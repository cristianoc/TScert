Support guarded quantified push and prove type-disjoint array spine apartness

verified
quantified-guarded-push.ts#buildChunksquantified-guarded-push.ts#appendNonEmpty

Why

In quantified-guarded-push-gap.ts (#394), buildChunks builds a (number[] | null)[] by pushing null or a non-empty number[] onto chunks under the loop invariant forall i in chunks: chunks[i] === null || 1 <= chunks[i].length, and appendNonEmpty calls row.push(w) then bag.chunks.push(row) on a ChunkBag holding the same invariant. Both functions were refused: - Array.prototype.push only propagated numeric element-slot clauses, dropping guarded clauses and element-length bounds. - No rule separated two array spines whose element types are disjoint ((number[] | null)[] vs number[]), and a spine growth on an inner element did not preserve monotone lower bounds (1 <= e.length). - row.push(w) did not derive 1 <= row.length from row's array type when row.length had not yet been read.

addedRule type-disjoint array spine apartness

Γ ⊢ p : T1Γ ⊢ q : T2spineApart(T1, T2)|p|, |q| ≤ 2
spine(p) ≠ spine(q)
(type-spine-apart)
spineApart(T_1, T_2) holds when both types carry an array spine, at least
one spine is mutable (invariant), and one spine's element type admits a
concrete witness excluded by the other spine's element type (or a tuple
element type excluded at a fixed index). Because a mutable array spine
constrains every element read and write at its element type, two such
spines cannot occupy the same heap address.

modifiedRule quantified invariant across Array.prototype.push

addedTheorem call postcondition step budget

isCallTerm(t) ∧ n ≤ 3 ⟹ SafePost(n, t, …)
Every function call and constructor invocation takes at least three small
steps before reaching a value, so call postcondition checking only needs
the n ≥ 4 case where depth-≤2 type-spine-apart has enough step budget
to unfold both enclosing record types and their array spines.

/**
 * @invariant forall i in this.chunks: this.chunks[i] === null || 1 <= this.chunks[i].length
 */
export type ChunkBag = {
  chunks: (number[] | null)[];
};

/** @ensures forall i in result: result[i] === null || 1 <= result[i].length */
export function buildChunks(widths: number[]): (number[] | null)[] {
  const chunks: (number[] | null)[] = [];
  /** @invariant forall i in chunks: chunks[i] === null || 1 <= chunks[i].length */
  for (let i = 0; i < widths.length; i++) {
    const w = widths[i]!;
    if (w <= 0) {
      chunks.push(null);
    } else {
      const row: number[] = [];
      row.push(w);
      chunks.push(row);
    }
  }
  return chunks;
}

export function appendNonEmpty(
  bag: ChunkBag,
  row: number[],
  w: number,
): ChunkBag {
  row.push(w);
  bag.chunks.push(row);
  return bag;
}

export type ChunkBag = {

export function pushAliasedChunks(
  bag: ChunkBag,
  other: (number[] | null)[],

  other.push([]);
  return bag;
}
