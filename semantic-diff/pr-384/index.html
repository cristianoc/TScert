Add indexed-element length clauses and eliminate #365 assumes in Pretext

verified

Why

Pretext's line walkers track a cursor (segmentIndex, graphemeIndex) inside a segment's per-grapheme array prepared.breakableFitAdvances[segmentIndex]. Three unsafe paperAssume sites tagged #365 in dev/paper-rules/pretext/src/line-break.ts (originally lines 573, 1190, and 1191, plus dev/paper-rules/repro-365.ts) assumed that graphemeIndex is a safe integer at least 0 (or 1) and within fitAdvances.length after reading breakableFitAdvances[segmentIndex]. The clause language had no way to bound a path by a property or length of a single array element indexed by another path (p[q].length), nor did footprints name the spines of nested array elements so such facts survive calls and writes that keep an array's reach.

addedDefinition semantics: indexed-element fact and nested element-spine region

atIndex(s, p, τ, g, B) holds at (ρ, h) ⟺
path s.p reads an array with spine entries ls, index term τ evaluates to
an integer 0 ≤ i < |ls|, and either ls[i] matches guard tag g (when
g = some t) or linear body clause B holds over the element at ls[i]
(its value, fields, lengths, and ambient free terms).
elemSpines(x, p) names the spine locations of every array stored in the
element cells of the array reached along x.p (category: spines).

addedRule single pass: establishing, restating, instantiating, and framing atIndex

- Establishing (atIndexFollows): an edge establishes atIndex from an
existing atIndex at a shared array site with equal index, compatible
guard, and body entailed over ambient linear facts (bodyClauseEntails);
from a checked element read element(r, x, j) whose value entails the
instantiated (or guarded) body; or from a quantified every over the
same array at an in-bounds index.
- Disjunction monotonicity (eitherMono): A' ∨ B' ⊢ A ∨ B when A' ⊢ A
and B' ⊢ B, checked once at the top of caseEntails before splitting.
- Restating (restateAtIndex, restateAddedAtIndex): when a slot leaves
knowledge or a linear/guarded fact over an element read's projection is
added, linear facts over element(r, x, j) restate as atIndex, and
atIndex facts inside disjunctions lower and lift across field reads and
writes (lowerAtIndexFact, liftEveryFact).
- Instantiating (instantiateAtIndex): an element read r = x[k]
instantiates matching atIndex atoms (including inside either),
omitting a guard whose tag the store's value facts already exclude
(valExcludesTag).
- Framing (atIndexSupport): supports atIndex by the array path at
grow, its spine at keep, its element cells at init (unguarded) or
keep (guarded), its index and free terms at keep, and elemSpines at
keep when the body reads the element's length.

addedLowering clause parser: indexed-element clauses

p[q] === null || t < p[q].length
⇝atIndex(p, q, some null, t + 1 ≤ e.length)
g === 0 ||(p[q] !== null && g < p[q].length)
⇝either(g ≤ 0, atIndex(p, q, none, g + 1 ≤ e.length))
At most one indexed array element per comparison; index path q is a safe
integer, and p's type is an array or nullable-element array.
