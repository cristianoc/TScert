Discharge guarded facts whose bodies are refuted by linear or type facts

verified

Why

A guarded fact x.p === tag || B (or x.p !== tag || B) only yielded its guard tag tag on x.p when its body B was syntactically impossible (0 ≤ -1, 0 ≠ 0, or a disjunction of syntactically impossible facts). When B was a linear constraint refuted by the held linear facts — for example obj.field !== null || x >= 0 under x < 0, or a record invariant this.data.items !== undefined || this.onlyItem >= 0 under flow.onlyItem < 0 — the verifier could not discharge tag on x.p for slot-type refinement or complementary guard elimination, refusing obj.field! with evidence search failed: no derivation of its cast claim.

addedRule heap knowledge: linear refutation of a guarded body

K ⊨ g(s.p) ∨ BK ⊨ ¬B
K ⊨ g(s.p) ∨ (0 ≤ -1)
(guard-body-refute)
Applied over every unconditional guarded fact of any path length p whose
body B is refuted by the held linear facts during link expansion, and by
the held linear facts and slot-type oracle during disjunction release. When
any guarded body is discharged, complementary guards on the same path or
its aliases are discharged alongside it.

modifiedDefinition heap knowledge: path guard tags

addedTheorem soundness of guarded-body linear refutation

For every environment ρ, heap h, knowledge k, and type oracle O
sound at ρ, if k holds at (ρ, h) then every guarded fact emitted by
linear refutation (g(s.p) ∨ (0 ≤ -1)) holds at (ρ, h), and both
disjunction/guard release and link expansion preserve knowledge validity.
Every path guard tag returned by a lookup table or single-shot tag query
witnesses readGuard h (ρ s) p = some v with tag holding of v.

type Holder = { field: { value: number } | null };

/** @requires safeInteger(x)
 *  @requires obj.field !== null || x >= 0
 */
export function readWhenNegative(x: number, obj: Holder): number {
  if (x < 0) {
    return obj.field!.value;
  }
  return x;
}

type Items = { halts: Float64Array | null };
type Data = { widths: number[]; items?: Items };

/** @invariant safeInteger(this.onlyItem)
 *  @invariant this.data.items !== undefined || this.onlyItem >= 0
 *  @invariant this.data.items === undefined || this.data.items.halts === null || this.data.widths.length <= this.data.items.halts.length
 *  @invariant this.segmentItems !== null || this.onlyItem >= 0
 *  @invariant this.segmentItems === null || this.segmentItems.length === this.data.widths.length
 */
type Flow = {
  data: Data;
  onlyItem: number;
  segmentItems: Int32Array | null;
};

/** @requires safeInteger(flow.onlyItem) && flow.onlyItem < 0
 *  @requires safeInteger(i) && 0 <= i && i < flow.data.widths.length
 */
export function readFlow(flow: Flow, i: number): number {
  const data = flow.data;
  const items = data.items;
  const rawSegs = flow.segmentItems;
  const segs: Int32Array = rawSegs!;
  const halts = items!.halts;
  const h = halts !== null ? halts[i]! : 0;
  return segs[i]! + h;
}
