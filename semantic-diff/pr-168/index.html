State the categories, selectors and exits the parity legs build on

no-behaviour-change

Why

The legs that bring the pass to the note's rules build against one vocabulary (drafts/parity-interfaces.md, I1 and declaration order item 1): the three categories of a location the note's class regions read, finite selectors of them with inclusion and disjointness as set operations, the two completions of a call with one specification each, and the four typed-array formats. Nothing used them yet, so the regions, the effects and the typed-array model could not be stated in the note's terms.

addedDefinition the category of a location

category(field) = category(cell) = category(elem) = category(identity) = value
category(store array) = array
category(store (view N)) = view

addedDefinition selectors of categories

A selector S is a set of categories.
S ⊑ T ⟺ ∀ c. c ∈ S ⟹ c ∈ T
S # T ⟺ ∀ c. c ∈ S ⟹ c ∉ T
values = {value}arrays = {array}views = {view}
stores = {array, view}all = {value, array, view}

addedTheorem selector inclusion and disjointness

S.sub T = true ⟺ S ⊑ T
S.disjoint T = true ⟺ S # T
values, arrays and views are pairwise disjoint and cover every category;
stores = arrays ∪ views; stores and views are not disjoint.

addedDefinition the exits of a call specification

Completion = normal | exceptional
Exits α = (normal : α, exceptional : α)
ExitSpec = (frame : effect, ensures : list of facts)

addedDefinition view formats

ViewFormat = uint8 | uint16 | int32 | float64

Read a signature's frame through one interpretation

no-behaviour-change

Why

A call signature's frame had two meanings: the footprint postcondition of its entries (within) and a separately defined closed reading (the coarse bound outside the receiver's own locations or store), related by a theorem in each direction. Consumers chose either, so a change to one could leave the other stating a different frame.

removedDefinition the closed reading of a signature's frame

withinClosed(e, r, h, h') := by receiver mode, the coarse bound on the
old locations outside r's own locations (with ownChange on them),
outside r's store, or on every location

addedTheorem projections of the frame

within(e, r, args, h, h') ⟹
the coarse bound on every old location no receiver entry covers;
with receiverOwn: ownChange on r's own locations;
with receiverStore: the coarse bound outside r's store
and conversely, without store regions, these give within(e, r, args, h, h')
(withinofown, withinofstore, withinoffootprint); a frame read
through a larger coarse bound with the same receiver modes and no store
regions is a frame of the larger signature at any actuals (withincoarse).

modifiedDocs SOURCE-ELABORATION.md, drafts/location-kinds.md

Cite the projections.
