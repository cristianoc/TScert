Admit the DOM's atob of a string, the forgiving-base64 decode, writing nothing

verified

Why

Pretext's line-breaks.ts#unpackTable and #unpackVarints decode their packed tables with atob, refused at the source gate: "atob(…) is not in the reviewed overlay of library globals". atob is a host function of the HTML standard (WindowOrWorkerGlobalScope), declared in the DOM's library; Node's global atob follows the same algorithm. It enters through the reviewed overlay of library globals, as the DOM's console.error and Node's structuredClone do.

addedTrust library-globals overlay: atob, the DOM's library

declare function atob(data: string): string, as declared, within the empty footprint, on a throw too. Web IDL converts data to a DOMString, which runs no code on a string; the forgiving-base64 decode returns a fresh string of the decoded bytes, one code unit each, or throws an InvalidCharacterError DOMException, an outcome.
