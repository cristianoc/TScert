Remove class-restricted regions and derive category bounds from well-formed states

no-behaviour-change

Why

Regions carried a recursive wrapper restricting a region to a category selector (values, array spines, view spines, or all) solely so untyped region inclusion and rebasing could infer that a field, spine, own-field set, or element-cell region stays inside its category. Every region constructor already has an intrinsic role bound proved at well-formed states, so the wrapper duplicated information, made the region syntax recursive (requiring fuel in the JSON decoder), and complicated checks, rebasing, and external frame signatures.

removedDefinition footprint semantics: class-restricted region

r ∩ cls(c) selecting locations l ∈ r whose heap entry satisfies selector c.

modifiedDefinition footprint semantics: class evidence and region inclusion

addedTheorem footprint semantics: intrinsic category evidence at well-formed states

Heap well-formed at world W ∧ valid roots for ρ at W
⟹ every allocated location l in any region r satisfies r's intrinsic
category selector.

modifiedWire request protocol: region grammar

modifiedDocs footprints, program typing, request protocol

Updated path read supports, bound disjointness, receiver frames, unlinked rebasing, and the Region wire grammar to match the removal of inCls.

Soundness

Every region constructor's intrinsic category bound follows from its proved role bound and heap well-formedness with valid roots. Untyped footprint composition, stability, and parity lemmas remain parameterized by abstract class evidence, preserving all negative controls in FootprintControls. Both axiom checks pass with no new axioms or sorry.
