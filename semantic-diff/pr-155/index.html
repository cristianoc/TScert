Add the bounds patterns of pretext's bound rewrites as pipeline cases

no-behaviour-change
bounds-pattern-visitor-refused.ts#afterWalkbounds-pattern-grow-upper-refused.ts#regionalbounds-pattern-postfix-prefix-refused.ts#fill

Why

An agent adding a bounds capability for pretext had no small set of cases that shows whether the capability's target shape verifies and whether its neighbours keep their outcomes. The 422 bound rewrite sites left in pretext (tscert-bounds 9268edb1) fall under 21 patterns, each the smallest program with one missing capability; their programs lived in a scratch directory, outside the suite.

addedExample

for each pattern, bounds-pattern-<name>-refused.ts, the pattern's safeprogram, a gap with its cause; bounds-pattern-<name>.ts, its supportedneighbours; and for P1, P2, P4, P5, P7, P15, P16 and P20,invalid-bounds-pattern-<name>.ts, an unsafe neighbour the capabilitymust keep refusing, run under Node. Each header states the pattern,the fact it needs, the pretext functions it stands for and the gap'scause.

Effect

  • the 21 bounds-pattern-*-refused new gap, each at the refusal the
  • patterns document observed on engine-rows (P9, P12, P17 at the
  • source; the others at the pattern's read, edge or return)
  • the 21 bounds-pattern-* new verified
  • the 8 invalid-bounds-pattern-* new refused; under Node NaN,
  • `undefined` at the asserted type, or a TypeError

Gap

Each pattern's capability; the headers state them. The programs the document did not run need a minimal fix to show the pattern: P5's cached table is first blocked by P16, so the table is decoded at each call; P13's charCodeAt needs no bound and its builder stated no postcondition, so the read is codePointAt(…)! and fill states the prefix it fills; P19's offsets was unrelated to segments, which is unsafe, so the view is allocated at the computed sum.

The feature-gap cases stand for pretext's functions, named in each header: that association is what keeps them under "Feature gaps follow the census" (CLAUDE.md, "Which tests to keep").

Why

It needs to know, in minutes, whether the capability's target shape verifies, whether its neighbours keep their outcomes, and whether any pretext function is lost.
