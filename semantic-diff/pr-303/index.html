State the outside contracts and the file-level theorems above a base world

no-behaviour-change

Why

The outside contracts required an outside slot's value to meet its type at every budget in every world, the empty world included. No value of a record type, a cell or any located type meets its type in the empty world: the world holds no location for its field (Fable's probe, recT_not_every_world). So for a layout with such a slot (a host object as Array.prototype, a module constant holding an object, a cell, a namespace import) the premise was false, and the file-level, interface and cross-module theorems held vacuously, their conclusions (every world) stronger than any run gives. The headline theorem reads none of them and keeps its statement.
