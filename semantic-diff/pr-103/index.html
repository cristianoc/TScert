Read a condition constant's equality as its tag test where it narrows the right operand of &&

Why

const prefixes = from === "a"; if (prefixes && n > 2) return onlyA(from) was refused: the edge into the arm had from at "a" | "b". The lowering claims the nodes of &&'s right operand in the context the left operand's true edge leaves, where the constant's implication narrows from. That narrowing reads the constant's initializer as recorded at its declaration, the source equality from === "a", which names no tag; the tests the execution runs read the same equality as the singleton test strEq "a" of from. So the implication narrowed nothing and the right operand's nodes kept the statement entry's from. pretext's getSegmentFit meets it (if (prefixes && profile.cutWordKeepsLigatures)).

// Refusal: reject: source expression obligation: no derivation of its cast
// claim.
// A non-null assertion of a `match` with a global regular expression, after
// another expression's `test` passed: the match is found because every code
// point the tested expression matches is one the matched one's class
// admits, an inclusion of Unicode properties that no type states.
const presentationRe = /\p{Emoji_Presentation}|\p{Extended_Pictographic}/u;
const stretchRe = /[\p{Extended_Pictographic}\p{Emoji_Component}]+/gu;

export function stretches(grapheme: string): number {
  if (!presentationRe.test(grapheme)) return 0;
  return grapheme.match(stretchRe)!.length;
}
  • blocker-pretext-code-point-at-assertion gap new → gap the loop's bound does not rule out undefined
    // Pretext (github.com/chenglou/pretext at 0d102a5c, src/, census by unit):
// prepare.ts#needsComplexTextPath, prepare.ts#getScriptFactsAt,
// prepare.ts#mayHoldCursive.
// Refusal: reject: source expression obligation: no derivation of its cast
// claim.
// A non-null assertion of `codePointAt(i)` with `i` a counter from 0 below
// the string's length: `codePointAt` gives `undefined` only at a position
// before the start or past the end, and the loop's bound is not used to
// rule those out.
export function astral(text: string): number {
  let count = 0;
  for (let i = 0; i < text.length; i++) {
    if (text.codePointAt(i)! > 0xffff) count++;
  }
  return count;
}
