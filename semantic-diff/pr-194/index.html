Define the serialized effect's codec over the exits, with its round trip proved

no-behaviour-change

Why

The effect's serialized form is to become the exits the effect holds. The old bridge proved only that its encoder writes what it represents; that decoding the encoding gives back the value was checked by examples. An unconditional round trip over every effect is false: the type admits assertion-arena references, executable terms as literals and unbounded nesting. The new form needs a predicate it holds on, a total encoder on it, and the round trip proved, before any document uses it.

addedDefinition the serialization predicate

An effect serializes when each formula of both exits references no
assertion-arena node, each literal it states is one of the calculus's
eight primitive constants (null, undefined, the Booleans, a number by
its bits, a string, a bigint, a symbol by its identity), and its
recursive constructors nest at most 256 deep. Every integer is written:
a safe one as a JSON number, any other as its decimal string.

addedWire the per-exit effect, not yet read or written by any document

{exits: {normal: {frame, ensures}, exceptional: {frame, ensures}}, promise, requires, pre}; each record an object of its fields, each constructor an object of one field, its name, or its name alone.

addedTheorem encoding then decoding

every serializable effect e: decode (encode e) = e

addedTheorem decoding

decode j = e ⟹ e serializes, and encode e is j up to the order of
object members

addedTheorem encoding is injective on serializable effects

encode e = encode e' ⟹ e = e'

    // Element writes of a typed array that keep a quantified fact over its
// elements (ARITHMETIC.md, "Quantified clauses"): an Int32Array write at a

/** @requires safeInteger(k) && 0 <= k && k < items.length && safeInteger(v) && 0 <= v && v < widths.length && v <= 2147483647 && safeInteger(j)
 * @requires forall i in items: safeInteger(items[i]) && 0 <= items[i] && items[i] < widths.length */
export function writeThenRead(widths: number[], items: Int32Array, k: number, v: number, j: number): number {
  items[k] = v;
  if (j < 0 || j >= items.length) return 0;
  return widths[items[j]!]! + widths[items[k]!]!;
}

/** @requires safeInteger(limit) && 0 <= limit && limit < widths.length && limit <= 2147483647
 * @requires forall i in items: safeInteger(items[i]) && 0 <= items[i] && items[i] < widths.length */
export function clampAll(widths: number[], items: Int32Array, limit: number): number {
  for (let i = 0; i < items.length; i++) {
    if (items[i]! > limit) items[i] = limit;
  }
  if (items.length > 0) return widths[items[0]!]!;
  return 0;
}
