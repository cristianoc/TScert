verified

Why

pretext's getWholeRunContext and getFontKanaKerning narrow a field of a parameter's object by a test and a write, then write another field of the same object, and read the first field back:

if (state.context === null) state.context = create(); state.font = font; return state.context;

The return was refused: "The available claim for state.context is null | { font: string }".
