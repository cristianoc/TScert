Check quantified bodies across an ordinary array overwrite

verified

Why

replaceChunk overwrites one row with [42], which satisfies the row length requirement. The verifier drops the whole quantified fact when it does not know which other indices read the written cell.

modifiedSemantics ordinary array spines

addedCheck bounded overwrite of a quantified array

at a bounded element writekeep the prior body at every index whose reads survive, and check it with the replacement value at the written index. A parallel read must have its own checked witness.

Effect

  • quantified-inbounds-overwrite positive new → verified each replacement meets the guarded length body
    // Overwriting an in-bounds element of an ordinary array (`chunks[k] = next`,
// `chunks[k] = null`, or a guarded nullable array) keeps the quantified
// invariant on all other indices (`i !== k`), because an ordinary JS array's
// element cells are distinct (`listT`), and checks the body clause at `k`.
// Safe (run under Node).
/**
 * @invariant forall i in this.chunks: this.chunks[i] === null || 1 <= this.chunks[i].length
 */
export type ChunkList = {
  chunks: (number[] | null)[];
};

/** @requires safeInteger(k) && 0 <= k && k < list.chunks.length */
export function replaceChunk(list: ChunkList, k: number): ChunkList {
  const next: number[] = [42];
  const chunks = list.chunks;
  if ((k & 0x7fffffff) !== k || k >= chunks.length)
    throw new RangeError("index");
  chunks[k] = next;
  return list;
}

/** @requires safeInteger(k) && 0 <= k && k < list.chunks.length */
export function clearChunk(list: ChunkList, k: number): ChunkList {
  const chunks = list.chunks;
  if ((k & 0x7fffffff) !== k || k >= chunks.length)
    throw new RangeError("index");
  chunks[k] = null;
  return list;
}

/**
 * @requires safeInteger(k) && 0 <= k && k < list.chunks.length
 * @requires next === null || 1 <= next.length
 */
export function replaceChunkNullable(
  list: ChunkList,
  k: number,
  next: number[] | null,
): ChunkList {
  const chunks = list.chunks;
  if ((k & 0x7fffffff) !== k || k >= chunks.length)
    throw new RangeError("index");
  chunks[k] = next;
  return list;
}

/** @requires safeInteger(k) && 0 <= k && k < list.chunks.length */
export function replaceEmpty(list: ChunkList, k: number): ChunkList {
  const empty: number[] = [];

  if ((k & 0x7fffffff) !== k || k >= chunks.length)
    throw new RangeError("index");

}

/**

export type ChunkList = {
  chunks: (number[] | null)[];

/** @requires safeInteger(k) && 0 <= k && k < alias.length */
export function overwriteAliased(
  list: ChunkList,
  alias: (number[] | null)[],
  k: number,
): ChunkList {
  const empty: number[] = [];
  if ((k & 0x7fffffff) !== k || k >= alias.length)
    throw new RangeError("index");
  alias[k] = empty;
  return list;
}

Soundness

Distinct indices of the spine read distinct cells. Unchanged reads preserve old clauses, and the new cell value must satisfy every clause at its index. Cell distinctness does not imply value inequality or separation from another array's spine.

Validation

The three case files exercise four safe replacements, an empty replacement, and an aliased replacement under Node. The IndexWrites Lean module and docs check pass. GitHub runs the pipeline and the ordinary and paper soundness build.
