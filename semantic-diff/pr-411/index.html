Why

Returning an object literal such as { chunks }, { chunks, extras }, or { inner: { chunks } } records non-optional read links from the fresh object's fields to the initializer slots, while the quantified every invariants stay rooted at the initializer slots. Add all-tag postcondition to %ArrayFilled% and prove vacuous every entailment (#393)

verified

Why

new Array<T>(n).fill(null) lowers to %ArrayFilled%(%ArrayLength%(n), null), whose intrinsic contract stated only result.length === n and not that every element holds the fill value. In addition, HeapKnowledge had no rule discharging a guarded single-array or parallel-array IndexFact.every clause vacuously from an all-tag array (forall j in b: b[j] === tag) with stop <= b.length, and BodyClause.HoldsAt required an explicit cell read for outer empty-elemPath guards even when an inner guard already held.
