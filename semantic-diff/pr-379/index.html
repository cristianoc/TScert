Why

Map.prototype.{set, delete, clear} and Set.prototype.{add, delete, clear} stated the closed footprint {value: scalar, spine: keep}. Because value: scalar covers every scalar field and cell in the heap, any field narrowing (c.label !== null), numeric field bound (0 <= c.i && c.i < xs.length), or module cell narrowing (state !== null) on an unrelated location was invalidated across m.set(...), m.clear(), or s.add(...) (refused with no derivation of its node-typing claim or an incoming-edge obligation), and functions calling these mutators could not certify Modifies<{ "m.size": "scalar" }, void> or Modifies<{ "s.size": "scalar" }, void>. In addition, the declaration reader emitted every overlaid interface method as a host-relative self member, whose calls bind the receiver and close slot 0 back to {value: scalar, spine: keep}.

type Cursor = { i: number; label: string | null };

/** @requires safeInteger(c.i) && 0 <= c.i && c.i < xs.length */
export function cursorAcrossMapMutators(
  m: Map<string, number>,
  c: Cursor,
  xs: number[],
): number {
  if (c.label !== null) {
    m.set("k", 1);
    m.delete("k");
    m.clear();
    return xs[c.i]! + c.label.length;
  }
  return 0;
}

/** @requires safeInteger(c.i) && 0 <= c.i && c.i < xs.length */
export function cursorAcrossSetMutators(

    s.add("k");

Soundness

Map.prototype.{set, delete, clear} and Set.prototype.{add, delete, clear} compare keys by SameValueZero, run no user code, and mutate only the receiver's internal slots (no location of the model) and its own size readonly view at scalar. Emitting these mutators as readonly fields taking the collection interface preserves subtyping (ReadonlyMap and ReadonlySet declare no mutators), refuses detached calls without a collection receiver, and closes {this.size: scalar} to {value: scalar, spine: keep} under .bind(...). Potential aliasing between two Map or Set parameters keeps their size fields overlapping by key (invalid-map-alias-invalidates-size). No Lean rules, semantics, or mode8Accepted_sound premises change.
