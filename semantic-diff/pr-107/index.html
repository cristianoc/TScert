Add a demo Python front end that hands a small subset of Python to the producer and the verifier

no-behaviour-change

Why

TScert's back end reads a Fragment document, not TypeScript itself, and nothing showed that another source language can reach it. A Python file such as def inc(x: int) -> int: return x + 1 had no way into the pipeline.
