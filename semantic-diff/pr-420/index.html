Support bitmask-guarded quantified clauses over parallel typed arrays (#398)

verified

Why

buildAndPatchPreservedSpace maintains parallel arrays flags (Uint8Array), advances, and extras where PRESERVED_SPACE (tag 2 under mask 0x7) entries never carry extras: forall i in extras: (flags[i] & 0x7) !== 2 || extras[i] === null After the loop, when (flags[patchAt]! & KIND_BITS) === PRESERVED_SPACE, it overwrites advances[patchAt] = [5, 5, 5]. This failed with source ensures refusal: a return of 'buildAndPatchPreservedSpace' does not establish the postcondition because linear terms lacked a bitmask projection, quantified body clauses could not combine a linear comparison disjunctively with an element guard, bitwise AND/OR did not propagate active masks, singleton numeric constants and tag-test equalities did not feed linear facts into atIndex restatements, and non-number overwrites did not keep parallel view-backed quantified clauses.

  const n = kinds.length;
  const flags = new Uint8Array(n);

  const extras: (number[] | null)[] = [];

      extras.push(null);

  }
  return { flags, advances, extras };
}
