Admit new Array<T>(n).fill(v) as one fresh dense array, its length checked before v

verified
rich-inline.ts#prepareRichInline

Why

pretext's prepareRichInline (rich-inline.ts, chenglou/pretext at 0d102a5c) makes a table on first need with xs ??= new Array<number[] | null>(n).fill(null). The source gate refused it: "new Array(…) is not in the reviewed overlay of library globals: new <T>(arrayLength: number): T[];". new Array(n) alone makes n holes, which a readable T[] admits only where undefined meets T, so the length constructor stayed outside the overlay. Filled at once by a fill of one argument, before any other code holds the array, the result has no hole.

addedLowering the parser: a length construct filled at once

new Array<T>(e₁).fill(e₂)
⇝%ArrayFilled%(%ArrayLength%(e₁), e₂)
side conditionthe construct is written directly as fill's receiver(no parentheses, no optional chain at the read or the call)
side conditionone argument, no spread, no type argument; TypeScript resolves fill to the standard library's fill(value: T, start?: number, end?: number): this of Array<T>
(any other use of the length constructor is refused, as before)

addedTrust intrinsics: %ArrayLength%, %ArrayFilled%

%ArrayLength% : (number) ⇒ number within the empty footprint %ArrayFilled% : ∀T. (number, T) ⇒ dense T[] within the empty footprint, its store fresh

%ArrayLength% is ArrayCreate's check: a RangeError where ToUint32(n) ≠ n, otherwise n. %ArrayFilled% makes an array of that length whose every index holds the value itself (an object value is one object all indices share). JavaScript evaluates e₁, checks the length, finds Array.prototype.fill, evaluates e₂, then fill reads the array's own length, takes 0 and the length for the omitted bounds without converting anything, and defines each index (neither Array.prototype nor Object.prototype owns a numeric key). The lowering keeps e₁, the check and e₂ in that order and allocates after e₂, which no code observes: nothing holds the array before fill returns it. Neither states its footprint on a throw.
