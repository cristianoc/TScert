Decide disjointness by the role classes of the regions' bounds

verified

Why

A fact about a field across a call was lost when the call's stated effect changed the spine of another array. The field is a field or a cell of an object, and the length read in the fact is a typed array's view spine, while the call changes an ordinary array's spine: no kind of location belongs to both, which the note's Definition "Derivations" calls disjoint. The knowledge's query answered disjointness by class only for the part of a region in one class against the class region of a disjoint selector, so it could not see this. With the heap's well-formedness and the environment's roots at hand, the bound of each region decides it.
