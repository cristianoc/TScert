Read a test's known answer at the tested binding's own type in the selected arm

verified

Why

Pretext's checked reads written inline, e ?? missing() with missing(): never, are refused in transformText (gecko-line-breaks.ts) at the second frameStarts ?? missing() of frame < (frameStarts ?? missing()).length && ((frameStarts ?? missing())[frame] ?? missing()) <= i: "evidence search failed: no derivation of its expression-claim claim", the claim number[] against the derived number[] | null. The lowering continues each arm of the first ?? separately, so in the right operand of &&, on the path where the first test found frameStarts present, its slot holds number[] and the second test's answer is known: only the present arm is built. That arm held the tested value at the type of the read frameStarts, which TypeScript types number[] | null, so the ??'s result was read with null in it.

export function missing(): never {
  throw new RangeError("missing value");

export function frameAt(frameStarts: number[] | null, i: number): number {
  let frame = 0;
  while (
    frame < (frameStarts ?? missing()).length &&
    ((frameStarts ?? missing())[frame] ?? missing()) <= i
  )
    frame++;
  return frame;
}

export function longer(xs: number[] | null): boolean {
  return (xs ?? missing()).length > 0 && (xs ?? missing()).length > 1;
}

Soundness

Give a member reference on a receiver that holds no value an empty location

verified

Why

Pretext's createLine (rich-inline.ts), with its checked reads written inline, is refused at (fragments[fragments.length - 1] ?? missing()).occupiedWidth -= rest: "an assignment needs one cell contract". The lowering continues each arm of the ?? separately; on the arm where the element is undefined the receiver is the result of missing(): never, of the type holding no value, and the compound assignment's location was looked up as a field of one record type, which that type is not.

modifiedLowering the location of a member reference

modifiedDocs PROGRAM-TYPING.md, WORK.md

The section on members of null and undefined states the location a reference names on a receiver holding no value. A WORK.md row records the inline checked reads: pretext with the guarded writes and every checked read inline verifies all its functions.

Effect

  • coalesce-missing-compound-member positive new → verified compound assignment through x ?? missing()
    // A compound assignment to a member of a checked read written inline,
// `(x ?? missing()).f -= d` with `missing(): never` (pretext's `createLine`,
// rich-inline.ts): on the path where `x` is nullish the receiver is the
// result of `missing()`, which holds no value, so no write is reached there;
// on the other the member is read and written at the record's field.
export function missing(): never {
  throw new RangeError("missing value");
}

type Fragment = { occupiedWidth: number };

export function trimLast(fragments: (Fragment | undefined)[], rest: number): void {
  if (rest < 0 && fragments.length > 0)
    (fragments[fragments.length - 1] ?? missing()).occupiedWidth -= rest;
}

export function widen(fragment: Fragment | undefined, by: number): number {
  return ((fragment ?? missing()).occupiedWidth += by);
}

Soundness

The location only names a field; the graph checker types the read and the write at the receiver's slot type, as on every receiver. A slot of the type holding no value is on no run's path.
