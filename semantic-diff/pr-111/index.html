Name pretext's rewrites in the headers of the handle, optional-field and navigator cases

no-behaviour-change
pretextsrc/layout.ts,src/measurement.ts#buildEngineProfile

Why

Pretext's layout.ts (chenglou/pretext at 0d102a5c, with the rewrites of issue #94) verifies 8 of its 17 functions: five pass a text's handle where the walkers' type adds an optional items, unsafe for an open record (invalid-optional-field-widening), and five assert the branded opaque handle to its record (blocker-pretext-opaque-handle-cast). The owner chose an honest structural handle: pretext's handle type is the record preparation builds, documented as internal, the brand dropped; the text handle states items?: never and the walkers read readonly items?; and measurement.ts reads navigator through { readonly userAgent?: string } (browsers only). With these rewrites (a patch to pretext, not in this repository) the census verifies all 16 functions of layout.ts and buildEngineProfile. The cases these functions stood for keep their roles, and their headers name the functions they still stand for.

    // Pretext (github.com/chenglou/pretext at 0d102a5c, src/, census by unit,
// with the rewrites of TScert issue #94):
// rich-inline.ts#getInternalPreparedRichInline. layout.ts states its
// handle's type as the record preparation builds, and asserts none.
// Refusal: reject: closure expression claim.
// A branded opaque handle asserted with `as` to its internal record: no
// claim of the handle meets the internal type's fields.
declare const handleBrand: unique symbol;
export type Handle = { readonly [handleBrand]: true };
type Internal = Handle & { widths: number[] };

function internal(handle: Handle): Internal {
  return handle as Internal;
}

export function count(handle: Handle): number {
  return internal(handle).widths.length;
}
  • invalid-optional-field-widening negative refused → refused header: pretext's rewrite
    // Pretext (github.com/chenglou/pretext at 0d102a5c, src/, census by unit):
// layout.ts#layout, layout.ts#layoutWithLines, layout.ts#measureLineStats,
// layout.ts#stepNextLine, layout.ts#walkLineRanges.
// Refusal: reject: source expression obligation.
// A record passed where its type plus an optional field is expected:
// TypeScript admits it, but a value of the narrower type may hold that
// field at another type: under Node, `layout({ widths: [1, 2], items: 5 })`
// returns undefined where a number is due, and no claim meets the parameter.
// Pretext's handle comes only from prepare(), which builds it without
// `items`; pretext states it in the handle's type (`items?: never`) and
// the walkers' (`readonly items?`), a rewrite of TScert issue #94.
type Data = { widths: number[] };
type LineData = Data & { items?: { count: number } };

function countLines(prepared: LineData): number {
  return prepared.items === undefined
    ? prepared.widths.length
    : prepared.items.count;
}

export function layout(prepared: Data): number {
  return countLines(prepared);
}
  • blocker-pretext-navigator gap gap → gap header: pretext's rewrite
    // Pretext (github.com/chenglou/pretext at 0d102a5c, src/, census by unit):
// measurement.ts#buildEngineProfile, which with the rewrites of TScert
// issue #94 reads it through `{ readonly userAgent?: string }` and verifies.
// Refusal: search: closure expression claim: the available claim for
// navigator is the host's Navigator, and the assertion requires a record
// whose `userAgent` is writable.
// The DOM global `navigator`, asserted to a record of an optional writable
// `userAgent` before the read: the assertion would grant a write of a
// member the host defines only a getter for.
export function agent(): string {
  return typeof navigator === "undefined"
    ? ""
    : ((navigator as { userAgent?: string }).userAgent ?? "");
}
