Proposed: state that shift, reverse and splice also write element cells

no-behaviour-change

Why

The paper's table of what each operation writes listed splice with pop and the assignment of a length, as writing the spine alone. The model follows ECMA-262: shift, reverse and splice assign to an index the value of another, so an index that keeps an element keeps its cell and the cell's contents change (Arr.shift, Arr.reverse in FootprintNatives.lean). The owner approved the correction.
