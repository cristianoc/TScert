Why

@requires h.o.ys === null || h.o.ys.length === h.n.length, the same @ensures, and the body c.i = 0 was refused at the return: "This return does not establish (h.o.ys !== null → h.o.ys.length <= h.n.length) && …. Known at the return: result.value : true". A field write kept an index fact only by its change's category rule (keptWith): a guard's path of at most one field (guardKept), a term's path of two fields or more only where the write alters no object. So the write dropped a guard through two fields, a spine separation through two fields, and h.lines.ys.length across a write of an object, though the write changes one location of key i and the paths read locations of other keys. A call already keeps facts through their supports (the note's Frame, effectKept); the write did not. In pretext this blocked normalizePreparedLineStart's postcondition, its handle invariant of guards through prepared.items.

  • guarded-fact-sibling-write positive refused → verified the write of c.i keeps the guard through h.lines.ys, in reset and across seek's loop
    // Pretext (src/line-break.ts at the bounds annotations):
// normalizePreparedLineStart, stepPreparedSimpleLineGeometry.
// A fact guarded by a null test of a field of a field, stated at entry, then
// a write of another object's field: every location the guard's path reads
// has a key other than the written one, so the write keeps the guarded fact
// and the return establishes it; so too across a loop writing that field.
type Lines = { ys: number[] | null };
type Handle = { widths: number[]; lines: Lines };
type Cursor = { i: number };

/** @requires h.lines.ys === null || h.lines.ys.length === h.widths.length
 *  @ensures h.lines.ys === null || h.lines.ys.length === h.widths.length */
export function reset(h: Handle, c: Cursor): boolean {
  c.i = 0;
  return true;
}

// The same fact across a loop whose body writes the cursor's field: the
// loop head carries the guarded fact, as no write reaches its guard's path.
/** @requires h.lines.ys === null || h.lines.ys.length === h.widths.length
 *  @ensures h.lines.ys === null || h.lines.ys.length === h.widths.length */
export function seek(h: Handle, c: Cursor): boolean {
  let i = 0;
  /** @invariant safeInteger(i) && 0 <= i */
  while (i < h.widths.length) {
    c.i = i;
    if (h.widths[i]! === 0) return true;
    i++;
  }
  return false;
}
