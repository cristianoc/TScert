Check every safe declaration of the library in the axiom check, in place of a list of names

no-behaviour-change

Why

The axiom check listed 1512 theorems by name in twelve blocks. Checking the acceptance theorem already covers every theorem it rests on, and a theorem the list does not name is not checked at all, so the list stood for a property: every declaration of the library rests on Lean's standard axioms. The check now states that property. It reads the axioms each module's .olean records for its declarations, so it walks no proof: 56084 declarations in under 2 s. Unsafe declarations, the runtime implementations behind @[implemented_by], are outside it: safe code cannot refer to them, so no proof rests on them (the six of the library depend on the compiler's lcProof). Lake replays a module whose imports are unchanged, so that the check covers a module added later is a fast check of the imports, which runs every time. First step before the separation of the paper's check, made first because it replaces the list that step would otherwise split.
