Why

Concrete non-ambient class methods and constructors without rest parameters discard extra arguments in JavaScript, just like module functions and unannotated constant closures, yet their contracts carried only their fixed signatures. Passing a class instance or constructor where an interface or constructor type binds more parameters (such as Skip's Resource.instantiate omitting context or a zero-arg Resource class passed as ResourceClass) was refused. Separately, tsc --declaration strips type annotations from private class fields in .d.ts files, causing the unannotated-declaration sweep to refuse any file importing such a class even though classInstance reads untyped ambient fields as readonly unknown.
