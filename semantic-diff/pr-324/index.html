4d4d76f3b · Cristiano Calcagno · Nov 21, 13:04

Read a native taking a function argument as outside code

no-behaviour-change

Why

The owner decided on 2026-11-21 to narrow step 1.3: a standard native's steps are the component's only when the component's code calls it at a call of a native and the native takes no function argument (push, fill, an element read, slice); a native taking one (map, forEach, reduce, find, sort with a comparator) is outside code, its call giving its operands out, its steps and its callbacks' outside, as at any framed call. Whether a native takes a function argument is read from its contract's parameter types. This ends the series of trust clauses: the rule at a call of a native no longer holds a callback's results, and (b′)'s clauses on passed values and callees' storage are unused.
