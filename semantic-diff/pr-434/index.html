Refute disjunctive facts from disequalities and refined slot types

verified

Why

In dev/paper-rules/pretext/src/graphemes.ts (findGraphemeEnds), the loop tracks @invariant state === 1 || count < i - start and after the loop tests if (state !== START_STATE) before writing ends[count] = end and incrementing count. Without an early if (start >= end) return 0 workaround, the verifier refused findGraphemeEnds because: 1. A loop exit drops i, and variable elimination only projected bare linear facts, dropping the disjunction state === 1 || count < i - start instead of eliminating i via i <= end to state === 1 || count < end - start. 2. Equality state === 1 distributes across || into two disjunctions (state <= 1) || P and (-state <= -1) || P. Disjunction release checked each disjunction alone against linear facts, so state !== 1 refuted neither arm individually, and it never consulted refined slot types (such as const START_STATE = 1, narrowed literal unions 1 | 2, or non-contiguous literal unions 0 | 2). 3. state = transition & ~CLUSTER_END uses a negative mask (-129), so bitwise & did not emit safeInteger(result) even though every 32-bit bitwise AND/OR yields a signed 32-bit safe integer.

modifiedRule disjunctive fact release

addedRule disjunctive variable elimination

When dropping slots D, for each unconditional disjunction A || B
whose one arm is a linear fact naming a slot in D and whose other arm
names no slot in D, Fourier-Motzkin elimination over the unconditional
linear facts connected to the dropped terms projects the linear arm off
D, preserving the disjunction past loop-counter exit.

modifiedRule bitwise integer result facts

/** @requires safeInteger(start) && safeInteger(end) && 0 <= start && start <= end
 *  @ensures safeInteger(result) && 0 <= result && result <= end - start */
export function countClustersLiteral(
  start: number,
  end: number,
  flags: readonly number[],
): number {
  let state = 1;
  let count = 0;
  /** @invariant safeInteger(start) && safeInteger(end) && safeInteger(i) && safeInteger(count) && safeInteger(state) && 0 <= start && start <= i && i <= end && 0 <= count && count <= i - start
   *  @invariant i <= start || count < i - start
   *  @invariant state === 1 || count < i - start */
  for (let i = start; i < end; i++) {
    const f = i < flags.length ? flags[i] : 2;
    if (f !== undefined) {
      if (i > start && (f & CLUSTER_END) !== 0) {
        count++;
      }
      state = f & ~CLUSTER_END;
    }
  }
  if (state !== 1) {
    count++;
  }
  return count;
}
