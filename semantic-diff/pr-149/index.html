Read a key one operand of an intersection states as a method as a method of the meet, in Lean

refused

Why

A value of Counter & { next: () => number; tag: string } may hold next on its prototype, which a spread does not copy: Object.assign(new Counter(), { tag: "t" }) is of the intersection and its copy has no next. Lean read the intersection as the model's meet, a record owning next as an invariant field beside the method, so the spread rule, sound for own data fields, copied it. Only the producer left next out of the copy: a claims document stating next on the copy of c in copied (the copy's expression claim set to the function's result row, nothing else changed) was accepted by --produce-unit and by --check-units on main.

addedDefinition type reader: a method met with a field

methodKeysOnly(Ref(φ; μ)) = Ref(φ ∖ keys(μ); μ)
where φ are a record's, dictionary's or callable's fields, views and
optional fields and μ its methods: a key some operand states as a
method is a method of the meet, as a class instance's methods are,
and the meet states no field at it.

modifiedDefinition type reader: the source meet, sourceMeetLists

addedRefusal type reader: an intersection mentioning a type parameter

An intersection mentioning a type parameter is read as the model's meet at each instance; one whose operands' rows state a key both as a method and as a field is refused at the annotation.

addedDocs SOURCE-CONTRACTS.md, "Methods met with fields"

The rule, the readers it serves (spread, in, own-key bounds, key listings, calls at the method's signatures), why the field's signature is not added to the method (method parameters compared bivariantly), and the type-parameter operand read at its instance.

  v: T;
  get: () => T;
  tag: string;
} {
  return { ...b };
}

Soundness

The method's denotation does not require an own property, so the meet with the field left out holds every value of the intersection whose key sits on its prototype; every reader of own keys reads the clause, so none takes the key for an own field. The field's call contract is left out, which only weakens what a reader may assume.
