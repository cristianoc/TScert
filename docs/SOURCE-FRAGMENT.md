# Source fragment boundary

The source fragment is the subset of TypeScript admitted by the parser and
source elaborator. The tables distinguish restrictions required by the
specified semantics from limits of the supported translation. A refusal
establishes that this pipeline cannot verify that source under its current
rules; it does not establish that the program is unsafe.
[Source contracts](SOURCE-CONTRACTS.md) gives the interpretation of annotations
and external declarations; [the trust surface](DESIGN.md#trust-surface) states
the assumptions used when connecting the extracted graph to JavaScript.

## Fragment boundary

What the pipeline refuses, each with its reason, in two classes. A refusal is
**principled** only when the construct is unsound, not faithful to
JavaScript, rejected by TypeScript, or safe only under an assumption the
project declines; any other refusal is a **model limit**, a gap, with the
obstacle named. A search failure is neither.

### Refused on principle

| Construct | Refused because |
| --- | --- |
| A read of an object at a key it may lack, where the key may name a member of `Object.prototype` (`toString`, `constructor`, `valueOf`, `__proto__`, ... — `objectProtoKeys`): an optional field or a dictionary's index under such a name, by a member access, a computed key or a pattern; a key known only at run time to be some string | Every ordinary object inherits those members; the model's objects hold no prototype there, so where the object lacks the key the model's read finds `undefined` and JavaScript's the member: `const d: { [k: string]: number } = {}; d["toString"] ?? 0` is a function (`invalid-dictionary-inherited-key`, `invalid-dictionary-inherited-named`, `invalid-optional-inherited-key`, `invalid-pattern-inherited-key`, each run under Node). A key the type proves own (a required field or view) is read under any name (`own-inherited-name`); so is a number key, a string singleton naming no member, and the entry a `for...in` step visits. The rules enforce it for every read form: `readOptional` and `readDict` take no inherited key (`inheritedKey`), and `indexDict` no key class of every string; a computed read at some string is refused at its site (`LoweringTypes.comparisonsExpr`). |
| An array `Array.isArray` or `instanceof Array` finds in `unknown` or a record, passed at a generic call's mutable `Array<A>` | The array may be a tuple, whose positions hold different types: no instance of `A` is its store's contract, and the callee may rearrange its `Array<A>`, which keeps every element an `A` but breaks the tuple's type: a `[number, string]` passed as `unknown` to a function calling `eachLen<A, B>(a: Array<A>, b: Array<B>)`, which reverses `a`, holds a string first (`invalid-open-array-generic-call`, run under Node). |
| `new Array(n)`, `new Array(x)` with one argument | A numeric argument constructs holes; a readable element contract excluding `undefined` cannot justify those reads. The source gate refuses the ambiguous one-argument form. |
| An element write at an index not proven in bounds or appending | It could create a hole. |
| A mutable `Dog[]` as an `Animal[]`, a mutable dictionary of `true` as one of `boolean`, a readonly view as a writable one | Mutable storage is invariant: a write through the wider alias breaks the narrower one's contract (TypeScript's covariance is unsound). |
| Method bivariance (`Handler<Dog>` as `Handler<Animal>`), an override with narrower parameters, a narrower constructor at a construct signature | The member may be invoked with the wider argument. |
| A method as a function-typed property, method extraction (`o.m.call(r)`, `.apply` and `.bind` of one included), a write to a method member; a function whose `this` is typed where a receiver-indifferent callback is expected | A method is host-relative: read off its host it loses its receiver, and TypeScript's typing of it is unsound. |
| A record type where an index signature or a dictionary is expected (TypeScript's implicit index signature); width subtyping into an optional field; an array where a number index is expected | A record is open: it may own further keys at any type; an array has a prototype a dictionary lacks. |
| A position past a mutable tuple's arity; its `length` read at the arity | `push` may have extended it: TypeScript's `undefined` there, and its literal length, are unsound. |
| Narrowing `unknown` by `instanceof C`, and a member read of the result | JavaScript gives an object `C`'s prototype without `C`'s constructor running (`Object.create(C.prototype)`, `Object.setPrototypeOf`, `Reflect.construct` with `C` as the new target), so "an object whose chain holds `C`'s prototype has `C`'s fields" is false of values a unit may receive. |
| `.call`, `.apply` or `.bind` of a function value a unit receives (a parameter, a field of one, a copy of either, a call's result) | A received function may own a `call`, `apply` or `bind` of its own, which its callable annotation does not constrain: a `read` returning a number whose own `call` returns a string makes `copy.read.call(r)` a string (`invalid-call-own-override`, executed under Node by `node-runs.mts`). |
| A spread of a value whose type states a symbol-keyed field, at a result stating that field | The caller contract requires a stated string-keyed field to be an own enumerable property, and no symbol-keyed one: an own non-enumerable symbol property meets the type and the spread omits it (`invalid-spread-symbol-nonenumerable`, executed under Node by `node-runs.mts`). |
| `instanceof` of a constructor not declared at the file's top level (imported, ambient, a function, an expression), but a name whose type states `[Symbol.hasInstance]`, which `instanceof` calls | Nothing in the file says which prototype it gives its instances; trusting it is an assumption declined. |
| A base class declared later, imported, ambient, or an expression | Nothing in the file says what its constructor allocates (TypeScript rejects the first). |
| `key in o` on an operand with a primitive arm or `unknown` | JavaScript throws on a primitive, and TypeScript rejects both. |
| A loop or an array pattern over an iterable whose iterator's type states no `return` | Leaving it early, or a throw out of its body, calls whatever `return` the iterator owns, and an open record type says nothing of that property. |
| Async return or non-promise `await` without a stable non-thenable contract | JavaScript adopts thenables. Ordinary arrays and lifetime primitive-valued or absent `then` contracts establish the supported bound; an arbitrary record type does not. |
| An object literal, class or parameter property the source builds with a `then` member, which could be claimed as a `Promise` | A value of type `Promise<T>` is assumed a built-in promise; the source must not forge one. |
| A write replacing a native promise's `constructor` or declared prototype members through any structural alias; an own `then` on an ordinary array | These violate the [native promise and stable non-thenable contracts](SOURCE-CONTRACTS.md#async-functions-and-await), including their requirements on external inputs. |
| A source declaration merged with the standard `Promise` interface | Native factories produce standard promises. Extra fields or overloads in a declaration do not establish that the returned values meet them. |
| An async return annotated with a nested promise when fresh resolution yields a non-promise payload | `Promise<A>` states the fulfillment value's type. The [async return rule](SOURCE-CONTRACTS.md#async-functions-and-await) checks the freshly resolved promise against that annotation; a number payload does not meet a promise payload contract. |
| `catch` or `finally` promising to preserve an open record payload without restricting its `then` | The fresh result resolves that payload again, which can adopt a callable `then` and change the fulfillment value. |
| A `finally` callback returning an open record without a stable non-thenable contract | Resolving the cleanup result invokes a hidden `then`, whose arguments and effects the record contract does not constrain. A native cleanup promise has a separate identity contract. |
| `String(o)`, `Number(o)`, `Math.max(o)`, `Math.min(o)`, `String.fromCodePoint(o)`, `String.fromCharCode(o)` (an object spread from an array too), `Object.getOwnPropertyDescriptor(x, o)`, `o + ""`, `new Date(o)`, `new Set(it)` of a non-array iterable, `JSON.parse` with a reviver, `JSON.stringify` with a replacer, of an array or an open record; a relational comparison with an object operand | The host runs client code (`toString`, `valueOf`, an iterator, a callback, a `toJSON`). |
| `Reflect` and its functions, `Reflect.get(o, k)` among them | `Reflect` is a namespace, no annotated variable, and `Reflect.get` runs [[Get]], which calls an accessor's getter, code no type of `o` states. |
| `+` on a bigint, number–bigint arithmetic, a symbol in a concatenation; a relational comparison of a string with a number | TypeScript refuses these operations. |
| `==` or `!=` that may convert an object to a primitive, including an array | Conversion may invoke client hooks and mutate aliases. Standard array string conversion does not justify default-hint conversion, which calls `valueOf` first. TypeScript reports an array compared with a primitive as having no overlap, so only a union reaches the conversion: too rare to justify a `valueOf` restriction and a runtime array dispatch ([utility](DESIGN.md#principles)). |
| `this` before `super(...)` | TypeScript rejects it, and JavaScript throws. |
| A read of a local above its declaration or in its own initializer; a parameter default reading a later parameter | JavaScript throws there (the temporal dead zone), and TypeScript rejects it (TS2448, TS2373). |
| An assignment to a module function's binding | TypeScript rejects it (TS2630). |
| A call of a `Function` value | It states no signature to call it at: TypeScript calls it at `any`, which states no contract. |
| A fresh callable given a field `call`, `bind`, `name`, `length`, `caller` or `arguments` (`Object.assign(f, { name })`) | An own `call` or `bind` would replace the intrinsic the parser identifies by lexical provenance ([trust surface](DESIGN.md#trust-surface)); a function owns `name` and `length` unwritable and inherits `caller` and `arguments` as accessors that throw, so JavaScript's copy throws where TypeScript types the callable with the field. |
| A class extending `Array` | Its instances' `constructor` is the subclass, so `map`, `filter` and `slice` construct their results through it (`ArraySpeciesCreate`), which [ordinary array construction](SOURCE-MODEL.md#arrays) excludes (`invalid-array-subclass`). |
| A catch binding annotated other than `unknown`, or destructured | Anything may be thrown; TypeScript's alternative is `any`. |
| TypeScript's `any` in the checked module's own annotations; a contextual closure parameter TypeScript types `any` | It states no contract. |
| A class in the checked module merged with an interface whose member its constructor does not give | A class merged with interfaces is one instance contract, every part's members: a value consumed at it reads them all (`merged-class-consumer-value-import`). The class's constructor must establish that contract, and is checked where the class is defined in the checked module: TypeScript assumes the interface's members on instances the constructor does not create, so `class C {} interface C { m: number }` types `new C().m`, `undefined`, as a number, and is refused at `C`'s definition (`invalid-merged-augmented`). An imported class's constructor is a trusted declaration, as every imported contract is. |
| A contract read through an unannotated declaration, whose type is inferred from its code: a declaration a type reaches (`typeof`, a member selection, a named type, a whole class, namespace or module) whose written annotations do not determine its exposed type ([the table below](#types-stated-by-annotations)) | Its type is whatever TypeScript infers from code the reader does not read, which may depend on any code; the bound obligations written there would go unchecked (`invalid-written-unannotated-call-value-import`, `invalid-written-whole-class-value-import`, `invalid-written-unannotated-field-value-import`). The client's own values carry annotations by the same requirement. |
| A rest parameter typed by what is no array | TypeScript rejects it (TS2370). |
| A rest parameter typed by an intersection (`...xs: T[] & (number[] \| string[])`) | Its declared contract can be empty at an instance TypeScript admits: at `T := boolean` no array is both a writable `boolean[]` and a `number[]`, writable storage being invariant, yet TypeScript accepts `f<boolean>()`, and a body writing through one operand's view returns a number as a `boolean` (`invalid-rest-intersection`, executed under Node by `node-runs.mts`). |
| A type parameter typing a rest parameter and anything else, in a module function (`<T extends readonly string[]>(...args: T): T`, a parameter `mutator: (arr: T) => void`, `const x: T = args`) or in a generic function or constructor type (`<T extends [string, number]>(...args: T) => T`) | The array a call collects is fresh: it holds the actuals and none of `T`'s other members, so it is no value of `T`. TypeScript admits `T := string[] & { tag: string }`, inferred from a spread of a tagged array, at which a body returning `args` gives a value whose `tag` is `undefined` typed `string` (`invalid-rest-pack-value`). In a generic type the instance `T := X` gives the rest the element lists of `X`'s members, `[string, number] & { tag: string }` included. Admitting it would need the element lists related to arrays a world extension holds (an array-allocation lemma whose statement is open: an array's `[[proto]]` holds a member of the built-in prototype type, which the model never shows inhabited), linked binder positions, quantified subtyping across binder counts and rest-bound reasoning: substantial machinery for a form rarely useful in real programs. A declaration's or a class's own type parameter typing a rest and a value is a [packed binder](PROGRAM-TYPING.md#packed-binders), whose instances are array or tuple types with no other members. |
| An instance other than an array or tuple type with no other members and no sparse holes, of a type parameter typing a value and a rest (`new RestRunner<number[] & { tag: string }>(…)` for `class RestRunner<T extends readonly unknown[]> { callback: (...args: T) => number }`) | The array a call collects is fresh, with the elements and none of the instance's other members: a [packed binder](PROGRAM-TYPING.md#packed-binders) ranges over the instances whose fresh arrays are their values, checked where the instance is named (`invalid-class-rest-binder-instance`). |
| A type that normalizes to nothing as a whole (`string & { a: number }`, `(() => void) & number[]`, `number[] & { map: number }`); as an arm of a union such an intersection adds nothing | No value of the model inhabits it (TypeScript keeps a branded primitive); it is refused rather than verified vacuously. |
| A write that may add a key (`x.k = e` where `x`'s type does not state `k`, a writable optional field, a key of an index; `x[k] = e` at a key known only at run time) through a parameter | The caller may hold the object at a type that leaves the key absent, or optional at another type: TypeScript accepts `const e = {}; const v: { k?: string } = e; f(e)` for `f(x: { [k: string]: number })` writing `x["k"] = 42`, after which `v.k` is a number typed `string` (`invalid-key-adding-parameter-write`, executed under Node by `node-runs.mts`). |
| A direct `eval` call (`eval(s)`, `(eval)(s)`); a binding named `eval` or `arguments` | A direct eval runs its string in the caller's scope, where it may read and write any binding the gate reads as the file states it; in sloppy code a binding of either name changes what the name means. |
| An empty module (no function, no initialization code) | Accepting it would check nothing. |
| An enum member initializer reading a member of its enum not yet initialized, or the enum itself, through a closure included; a call in one that can read the enum | JavaScript reads the member, or the partial object, before the emit writes it: `enum F { A = ((): number => F.B)(), B = 1 }` gives `F.A` undefined, typed `number` (`invalid-enum-computed-forward`, `invalid-enum-computed-call-order`). |
| `RegExp.prototype.compile` | It replaces an existing regex's pattern and flags, and with them the capture shape its type states: `/(a)(b)/` compiled to `"c"` matches with no group (`invalid-regexp-compile`, run under Node). |
| `matchAll` or `replaceAll` of a regex no literal made (a `RegExp` parameter) | Before dispatching, the host reads the argument's `Symbol.match` and `flags` and converts `flags`, which runs an object `flags`'s `toString` (`invalid-regexp-structural-matchall`, run under Node); a native regex's `flags` is the standard string ([regular expressions](SOURCE-CONTRACTS.md#regular-expressions)). |
| An enum member named `__proto__` | TypeScript's emit writes a member by assignment, which for `__proto__` runs the prototype's setter and creates no property: `enum P { "__proto__" = 1 }` makes `P.__proto__` `Object.prototype`, typed `1` (`invalid-enum-proto-member`). |
| A member named `NaN` or `Infinity` in an enum with a member TypeScript computes no value for | That member's reverse mapping is written at its value's key, which may be the name: `enum Q { NaN = 1, X = "x".charCodeAt(1) }` makes `Q.NaN` `"X"`, typed `1` (`invalid-enum-computed-nan-name`). |
| An enum of the compiler API's package read as a value where the [compiler-API contract](COMPILER-API.md) does not list it (`CharacterCodes`) | The contract reads a host enum's object only where a check binds its declaration to the runtime object (C1): `CharacterCodes.ogham` is 5760 in the declaration and 5765 at run time (`invalid-compiler-api-unlisted-enum`). |
| A write of a namespace member (`ns.x = e`, `ns.x++`, `delete ns.x`, a destructuring target) | A member is an import binding, which a module namespace object's [[Set]] and [[Delete]] refuse: JavaScript throws a `TypeError` (`invalid-namespace-member-write-value-import`, run under Node). |
| A use of a guard's argument that relies on the guard's `false` outcome (`if (isPositive(v)) …; v.toUpperCase()` with `v: number \| string`) | The promise states the `true` outcome only. TypeScript also narrows the `false` one to the arms outside `T`, wrong for a guard answering `false` for some values of `T`: `isPositive(-1)` is `false` for a number, and `shout(-1)` calls `toUpperCase` on it (`invalid-type-guard-false-branch`, executed under Node by `node-runs.mts`). |

#### Types stated by annotations

The written annotations that determine a declaration's exposed type, by its
kind. These, and only these, are read for a declaration a type reaches; no
function body, initializer's code or static block is read. A declaration
without them is refused (above). The structure is the checker's symbols, not
syntax: what a name or a selection denotes is one symbol, its annotations
the union over its declarations (an overload set's, an accessor pair's, a
merged entity's); a class's members are its instance and static member
symbols, apart; a module's or namespace's are its exported symbols,
`export =`, a default export and ambient members included. A member under
a computed name, which the checker binds late, counts by its declaration,
and its name's entity is swept. A name path, `typeof E.p₁…pₙ` (a qualified name, a property access, a
`typeof` or import type), contributes the determining annotations of every
declared entity on it: the root, which must have them, and each later step
with a declaration, with everything those annotations name. A step the
checker synthesises (a mapped type's member, an instantiation's) has no
declaration and needs none: its type is computed from annotations already
swept. A module or namespace a further step selects from contributes
nothing itself.

| Declaration | Determined by |
| --- | --- |
| Interface, type alias | Its whole syntax |
| Variable, binding element, parameter | Its own annotation, or its enclosing pattern's; a `const` initialized by a literal naming nothing (a string, number, bigint, Boolean or `null`, signed or parenthesized, an object or array literal of these, `as const` or not), each destructuring default on the way a literal too |
| Property declaration or signature | Its annotation |
| Property assignment, default export | Its value's: a literal naming nothing; a function's parameter and result annotations; a nested object literal's properties, each by its kind; an assertion's type (`as` or angle-bracket) |
| Function, method, signature | The symbol's overload signatures if it has any, else its parameter and result annotations |
| Accessor | The symbol's getter result or setter parameter, either for the pair |
| Constructor | Its parameter annotations, or its overloads' with the implementation's parameter properties |
| Class | Its type parameters, its heritage, and every instance and static member symbol |
| Namespace, module | Every exported symbol, `export =` and a default export included |
| Enum, enum member | Its value |

### Model limits

Sound JavaScript that TypeScript accepts, refused because the model or its
representation cannot state it yet; the paths are in
[next steps](../WORK.md#next-steps).

| Construct | Obstacle |
| --- | --- |
| `f.call(r)`, `f.apply(r, l)` or `f.bind(r)` of an `f` that is no known local function ([calls through `Function.prototype.call`](SOURCE-ELABORATION.md#calls-through-functionprototypecall)): a parameter, a call's result, a `let` some write gives such a value, a member a later spread may replace, a local or file-level function passed to other code or copied onto by `Object.assign`, an exported function | A function a caller supplies may own a `call`, `apply` or `bind` property, which its function type does not constrain; the caller contract states no exclusion of them. |
| `catch` or `finally` after a void async completion, through a `Promise<void>` annotation | That completion fulfills with `undefined`, but `void` denotes `unknown` and the annotation loses this evidence. An arbitrary `Promise<unknown>` payload can contain a hidden callable `then`, so discarding the result alone cannot justify re-resolution. |
| A write adding a key (`o.x = 5` where `o`'s type does not state `x`, a writable optional field, a key of an index) to an object another reference may hold: a module constant, an object a local did not allocate itself, a local whose object was passed, stored, captured, returned, bound to a `let` or written into itself, or a write in a loop the allocation does not enclose | The model's objects keep their keys, and a key is added by copying the object, rebound to every local holding it: another reference would still see the object without the key, where JavaScript's sees it with. |
| A write at a string key known only at run time (`d[k] = v`) of a value that may be an object or `null`; a key-adding write at a key that may be a string or a symbol | The key may be `__proto__`, whose setter, where the object does not own the key, makes such a value the object's prototype, and the copy that adds a key adds no prototype; the copy is made onto the object for a string key and onto the key's allocation for a symbol key. |
| A write of `__proto__`; adding a symbol key to an object whose type does not list its keys | The first runs the prototype's setter and adds no key; the copy of an object takes its string keys, and the symbol keys such an object may own are not known. |
| `Object.assign` onto an object other than a fresh literal or, as a statement, a local's own object; from a source whose type does not rule out an own `__proto__` | Its value is its target, and another reference would see the keys it adds; it sets `__proto__` through the prototype's setter, which replaces the prototype. |
| `===` or `!==` between two operands neither known to be a primitive or an object (`unknown`, a type parameter's value); narrowing by object identity | Two such values may be of no kind the operator decides; a statement entry states no slot equality. |
| `keyof T`, `T[K]` over a function's own type parameter (an alias computed from its parameters is evaluated at each application) | They are functions of the type an instance names (its declared, optional and readonly keys); a parameter row denotes a value set, which does not determine a key set. |
| A template literal type with a `${string}` hole; `keyof` with a unique-symbol key; `typeof` of a binding whose inferred type is not an object literal's record of literals and primitives, or of a class with a static method or a private static | No term of the fragment states it exactly: a static method is a binding of its own, which no member of the class value's type states. |
| An intersection with a union holding a type parameter, `(T \| null) & A`; a function type met with a record of readonly or optional fields, methods or an index | It distributes into meets known only at an instance; no clause states such a callable. |
| `declare let`, `declare var`, a module-level `let` or `var` | A unit's module inputs are immutable slots; module storage needs cells every call may write. |
| A NaN or infinite member; a reverse key naming a member; an empty enum | A NaN or infinite value has no literal type; the reverse entry would replace the member; an empty object leaves no record. |
| A `this` read in sloppy code whose receiver type may hold a value other than an object (`this: unknown`, `this: string`, no `this` annotation, a type parameter) | A sloppy call converts such a receiver (the global object, a wrapper), which the model has no step for ([graph code](SEMANTICS.md#graph-code)). |
| A library class other than `Array` as a base (`extends Map`) | Construction allocates an ordinary object at the class's fields; a library constructor's instance has no construction rule. |
| `key in o` for a string literal key the built-in prototypes hold (another key is the host's `%HasProperty%`, a Boolean narrowing nothing); a class value as the operand of `in`; `key in x` on an `unknown` a `typeof` test found an object (`typeof x === "object" && x !== null`) | The model holds no key of the built-in prototypes and would answer otherwise than JavaScript; a class value holds its static fields, but not its static methods, `name`, `length` or `prototype`, which JavaScript's owns; a `typeof` test answering `"object"` gives `unknown` no narrower type, and `in` needs an operand of object types, as it throws on a primitive. |
| A user-defined guard that is generic, or a guard closure collecting a rest array; a guard about the receiver (`this is T`); `asserts x` without a type; a promised actual other than a name (`isWord(node.name)`) | The producer encodes no quantified promise signature, and states none beside a closure's own variadic signature (`type-guard-generic-refused`, `type-guard-rest-closure-refused`); the receiver has no slot among the promised actuals (`type-guard-this-refused`); a promise of truthiness names no type of the fragment (`type-guard-asserts-untyped-refused`); a property's value after the call is known only while nothing writes it, and the call may write it: the guard's promise is no heap-preservation guarantee. It lifts with a no-write effect proved from a source guard's body, and, for a declared library guard, derived from its source by the [compiler-API](../WORK.md#next-steps) contract. |
| A promise about objects decided by tests of an `unknown` (`v is Record<string, unknown>` by `typeof v === "object"`) | A `typeof` test answering `"object"` gives `unknown` no narrower type (`type-guard-object-refused`). |
| An array pattern over an array another reference may hold (a source other than an array literal) in which code that may change an array runs after one of its steps and before a later one: a target's receiver or key, or a default, that calls, converts an object or writes other than a local; a write at a field target's index or `length` | JavaScript steps the array's iterator, which stays finished once a step found the end; the lowering reads each position when its step runs, which is the step only while nothing grew the array after a step found its end. `[, box[(xs.push(1, 2), "slot")] = 9] = xs` with `xs` empty writes 9, where a read of position 1 finds 2 (`array-pattern-exhausted-refused`, `array-pattern-exhausted-rest-refused`, `array-binding-exhausted-refused`, executed under Node by `node-runs.mts`; `array-pattern-steps` verifies). |
| An accessor (`get`/`set`), `__proto__`, a computed key in a literal other than a `unique symbol` constant | The heap has data properties only; the key is known only at run time. |
| A literal or class member keyed by a well-known symbol other than `Symbol.iterator` and `Symbol.hasInstance` (`Symbol.toStringTag`, `Symbol.toPrimitive`, …) | It changes how the host treats the object, which the model does not state; a tag would let it pass for a host collection, whose iteration is trusted. `Symbol.hasInstance` is read by `instanceof` alone, off its right operand: a key of a literal or a prototype is an ordinary key, and `instanceof` calls the one its right operand's type states, a class's static one or a readonly property of a construct type ([source elaboration](SOURCE-ELABORATION.md#derived-source-forms)). |
| An element read past a readonly tuple arm's length (`const [a, b] = t` with `t: readonly [number] \| readonly [number, string]`) | No element rule reads `undefined` beyond an exact length. |
| A rest parameter of a closure, or of a definition typed by an enclosing declaration's type parameter; a function type's rest typed by a class's or declaration's type parameter inside it that types no value there (one typing a value too is a [packed binder](PROGRAM-TYPING.md#packed-binders)); one typed by a type parameter whose bound is no array or tuple of required positions written as one; one typed by a tuple with optional or rest elements | A closure's scheme reads a bound as the meet of its binder with it, and argument lists have no meet row; inside a declaration its type parameter is a value type, whose values' elements the heap holds, where an argument pack's contract is heap-free; a module function's [pack rest](PROGRAM-TYPING.md#judgments-and-constructor-views) collects into the array its bound states; several lengths are several signatures. |
| A written `let` pattern in a `for` head, or a written `let` in a `for...of` head; a test of a written `let` held in a cell holding a union of objects, other than one excluding `null` and `undefined`; a `let` captured by a closure in a `for` loop | Its bindings are cells, which only a statement of a block lowers them to; a cell's known contents are primitive or merely no `undefined`; JavaScript copies the binding per iteration, which the lowering does not. |
| An array pattern over a value that may not be an array | The pattern reads an array's positions; over a host non-array iterable it would step `%Iterate:K%`, which the lowering does not place. |
| A generic or optional method declaring `this: T`; an optional method of a type literal nested in a declaration; a generic class method with a bounded binder; a constructor's rest parameter; a constructor parameter default, or a statement, reading `this` before the instance is complete | A generic method's member is a scheme its member bound to the host meets at every receiver, which states no type the host must meet, and an optional method is an optional field, whose function takes its declaration as receiver, which a nested literal is not; a generic class method's bounded binder, whose row its bound names; `new` constructs only code without a rest; the instance is allocated at the end of the constructor. |
| A class member with a computed key other than a method's `unique symbol` constant or a static `[Symbol.hasInstance]`; an index signature in a class; a static block reading `this`; a class extending a generic class other than at the base's own binders | A method is a binding and a prototype key named by its plain name or its symbol; instances are what construction allocates; the block's receiver is the class value, which JavaScript's block reaches with later static fields undefined and the model allocates only after them; a generic base's construction is at its binders' rows ([classes](SOURCE-CONTRACTS.md#classes)). |
| A class with a private name in inheritance; `#x in o` | A derived instance's base part is a copy, and a copy holds no private slot; the test asks for an own slot, where the model's key test walks the prototype chain. |
| A read of a static member through a class that inherits it from its base; `typeof C` of a class inheriting a static member | The class value reaches it through its prototype, the base class value, which the model's class value does not hold, and its type states no inherited member ([classes](SOURCE-CONTRACTS.md#classes)). |
| An instance member or constructor reading a private static field of its own class; a static initializer or block reading its class other than through an earlier static field (calling a static method whose body reads it, constructing it where construction reads it or runs code), or creating a closure that reads a static field; a static field without an annotation whose type TypeScript gives no term states; a static method that reads `this`; `super` in a static member; a mutable static field | Private static fields are bindings the class defines after its methods and constructor, whose closures cannot hold them; JavaScript's class value exists during the initializers with later static fields undefined, where the model allocates it holding them after every initializer, so a construction may read a static not yet defined (`undefined` in JavaScript), and a closure may read a field after it changes; the class value's type states each static field's type; a static method's receiver is whatever its call passes, and its `super` the base's class value, which the derived one does not hold as its prototype; a mutable static is module state. |
| `o.m?.()` | It would call the tested value with a receiver the lowering does not save. |
| A generator function (`function*`); `for await` | A body suspended at `yield` is no term of the calculus; an async iterator's steps are promises the model does not adopt. |
| An array literal hole (`[a, , b]`); an array literal with a spread claimed at a tuple of fixed positions (`const t: [number, ...number[]] = [1, ...xs]`) | A literal allocates one location per element, and a hole is none; with a spread, the store's length is known only at run time, so every position is at the claim's one element type ([literal with spreads](PROGRAM-TYPING.md#a-literal-with-spreads)). |
| A library global both constructed and read through members, or both called and read through a method (`new Date()` beside `Date.now()`), other than members the overlay reads as intrinsics (`Symbol.for`, `Symbol.keyFor`); an object type with construct signatures and members other than required properties beside one construct signature | A library class value or callable object with members has no clause; a class value's type states one construct signature and its static fields, required data properties, invariant or readonly views ([classes](SOURCE-CONTRACTS.md#classes)). |
| Any library signature the overlays do not list (`Math.random`, `concat`) | Not reviewed; nothing is trusted by default. |
| A regex's property (`lastIndex`, `source`, `flags`, a flag); `in` with a key a regex owns or inherits from `RegExp.prototype`, whatever the operand; a regex where a record stating such a key is expected | The model's regex states methods only: `lastIndex` is an own property that is not enumerable, which a copy lacks (`invalid-regexp-lastindex-view`, run under Node), the others accessors of `RegExp.prototype`, and the model's own fields are enumerable. |
| A regex replacement callback; `new RegExp`; a write to a match result | Not stated: the callback's arguments follow the shape, dynamic construction has the conservative one, and match results are readonly views so that a literal's precise result meets the conservative one. |
| A loop or spread over a value TypeScript types `RegExpStringIterator` that no native regex's `matchAll` returned (a parameter, an external result) | The host's iteration is assumed of the native iterator alone, whose type states its mark; another iterator would be stepped through the iterator protocol, which the lowering does not choose by TypeScript's type. |
| `&`, `\|`, `<<`, `>>` or `>>>` of two bigints | The model states these operators on numbers alone (`numberOnly`), whose `ToInt32` and `ToUint32` run no code; a bigint shift's result grows with its count, and `>>>` throws on bigints (`invalid-bitwise-bigint`). |
| An imported `const enum` read as a value | A `const enum` has no object: TypeScript inlines its reads, which the reading of an imported declaration does not state. |
| A namespace import mentioned other than by a member read or a qualified type name (`const m = ns`, `ns[k]`, `ns?.x`, `{ ns }`); a call `ns.f(…)` of a member whose signatures state a `this` parameter | A [namespace import](SOURCE-ELABORATION.md#derived-source-forms) is read as one binding per member, and the namespace object itself, a value with its own keys, is no such binding; the call passes the namespace object as the receiver, a call of the member's binding `undefined`. |
| A non-library global read other than through a member or a call (`const p = process`) | A global is assumed at the members and calls its references select; a read of the value selects none. |
| A module function without a result annotation | Its slot is its annotated signature, at which its unit is checked and every call reads it. |
| A mention, in a closure written above it, of a local that shadows an outer binding | JavaScript gives the name to the local from its block's start, and the closure reads it once it is initialized; the parser's renaming binds it from its declaration on ([shadowing](SOURCE-ELABORATION.md#derived-source-forms)). |
| A name declared in one `switch` clause and read in another | The clauses share one scope, where the lowering gives each clause's statements a scope of their own; a read reached by falling through, or through a closure, finds the binding initialized. |
| A function declaration after a statement that always jumps | The lowering drops what follows a jump; the declaration is hoisted, so live code may name it. |
| An actual that runs code after a spread into an ordinary call's fixed parameters | The call reads a spread's elements once every actual is evaluated; the lowering copies a spread where it is written only into a rest. |
| A spread of a program's iterable after an operand that runs code; a default or a nested pattern in an array pattern over a program's iterable | The iterator is run before the statement, and a pattern's names are bound after its steps: the operand's or the default's code would run in another order than JavaScript's. |
| A call through a union of functions carrying fields | The producer claims a call through one arrow the actuals call, which such a union does not offer. |
| A constructor writing a field that has an initializer, or writing one field twice | The instance is allocated at the constructor's end, from one value per field. |
| Constructing through a value of a generic constructor type (`new make(1)` with `make: new <T>(value: T) => Box<T>`) | A construct scheme has no instance rule: elimination (`inst`) instantiates call schemes only. |
| A bounded generic function type met by a generic closure or a generic module function (`const k: <T extends string>(x: T) => string = keep`) | The annotation's scheme reads its binder as its meet with the source values, the closure's or function's as its meet with its bound; quantified coverage does not use the bound to relate the two. |
| A generic class's instance member or constructor reading its own class | The class value is quantified over its declaring unit's binders, which the unit reads as parameter rows, and a module value is read only at ground instances. |
| An unannotated `let` of `null`, `undefined` or `[]` whose writes grow with it (`r = { tail: r }`) and whose uses expect no one type | Its contract is the union of what is written into it, which has no fixed point there, or the one type its uses expect, which none states. |
| A `let` with neither an initializer nor an annotation (`let y;`) | TypeScript types it as an evolving `any`; the pipeline reads a local's contract from its annotation or its initializer, and infers none from its later writes. |
| An imported interface its module declares more than once | The declaration reader resolves an import to one declaration; the merge of an interface declared twice is read for the checked file's own declarations ([interface merging](PROGRAM-TYPING.md)). |
| A closure parameter without an annotation that TypeScript types by an object type written nowhere by name | The parameter's annotation is TypeScript's contextual type, which the parser writes only through primitives, literals, arrays, tuples of required positions and a rest, type parameters and declarations by name. |
| `unknown` used as an array after `Array.isArray` or `instanceof Array` | The array invariant is stated of record and dictionary members; `unknown`, which a handler binds a thrown value at, carries none ([next steps](../WORK.md#next-steps)). |
| `Object.assign` onto an array | The copy takes the target's fields but its store, so its result would be no array. |
| `\|\|=` or `&&=` on a target other than a Boolean | The lowering tests the value read as a Boolean. |
| A source key spelling one the model keeps for itself (`"[]"`, a name in double brackets) | The model holds an array's store and an object's prototype under those keys: an object owning one would be read otherwise than JavaScript reads it. |
| A source property name beginning with `[!` (`{ "[!x": 1 }`) | Computed string keys are escaped (`escapeKey`); literal property names are kept unchanged. Names beginning `[!` are refused because these representations would differ. |
