Each ts.isX(n) is a call of TypeScript’s compiler API that tests n.kind, a field holding one of about 300 numbers, the members of the enum ts.SyntaxKind. Each guard that answers false adds a fact: n.kind is one of the numbers the earlier guards did not take.

Heap facts at successive points of the condition, with the rule, read from the evidence:

2, 6, 12, 20, 30, 42, 56, 72, 90, 110, 132

After k guards there are k × (k + 1) facts: both the facts on each slot holding n and the number of those slots grow with k (“What the points hold”, next). So the count grows with the square of the guards; each fact lists about 300 numbers.
