Four factors multiply; the first three grow with the number of tests n:

  • Facts per slot: one per failed test, about n.
  • Slots holding the object: they grow with the tests: 6, 10 and 18 at 4, 8 and 16 tests (n + 2).
  • Distinct points: each test’s edges carry their own knowledge, about n.
  • Values per fact: the size of the field’s type: 100 for Kind, about 300 for SyntaxKind.

So the stored values grow as about n³ times the type’s size, and the evidence 5 to 7 times per doubling. The growth is there without the rule.
