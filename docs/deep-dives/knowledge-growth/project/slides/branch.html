A rule that keeps the facts across a call

The rule call-keep: a call whose declared effect (the fields its declaration says it may write) writes no field of an object that existed before the call keeps every heap fact (soundness proved in Lean, PromiseCalls.keepsHeap_prefix). Before it, every call ended with no heap facts. The branch also adds link-fact (a field read into a slot holds one of the values the slot’s type allows), which gives the extra fact per slot in 18 → 24.

Before the rule

each ts.isX(n) in visit is a call, so it ended with no heap facts, and no guard’s answer survived to the next guard: 0 facts.

With the rule

the compiler’s guards change nothing, so their calls keep the facts. The eleven guards now behave like a condition of eleven === tests: 132 facts.

The rule was reviewed as sound, and is. It did not create the growth: it removed the calls that had been hiding it.
