The mistakes

Three mistakes let it through

1 · Storage with no normal form defect

Facts := List Fact (HeapFacts.lean:199): knowledge holds when every fact in the list holds. Nothing keeps one fact per field: a new fact is never merged with the facts on its field, a fact names a slot rather than the object, and an answer is the full list of values it leaves. All three are in the repository’s first commit, 2026-10-16.

2 · No test of how it scales defect

TScert’s test cases are small: each tests a few conditions, so a cost that grows with the length of a condition passes them all. No test measures how the evidence grows when a construct is repeated.

3 · Cost was not part of the merge defect

The branch measured only the functions it targeted (setLiterals: 433 KB of evidence in the census after the merge). The review asked about soundness, generality and tests. The integrating session, Claude, merged on passing tests. Only the census after the merge measured cost.
