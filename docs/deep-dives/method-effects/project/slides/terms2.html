Words used in this deck, continued

Three more cards

Certified, relative

A statement is certified when the checker has checked the function’s own body against it, in a run that verifies (a run: TScert checking one source file, or a slice, “More terms, for TScert’s own source”; it verifies when every function in it does). A function that relies on a statement not certified is verified relative to it: proved assuming the statement holds.

Contract

TScert’s description of a built-in or library function, such as Array’s map or a method of TypeScript’s compiler API: reviewed by hand, and in parts proved in Lean (which parts: “Built-ins state footprints in their contracts”) against the steps the ECMAScript specification gives the function (lean/Verification/Semantics/FootprintNatives.lean).

Test case

A source file of TScert’s test suite with its expected outcome, verified or refused, such as method-effect-map.ts. A refused test case passes when TScert refuses it with the expected diagnostic.
