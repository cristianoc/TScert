The footprint F

Two dials: ordinary locations and arrays

In TScert’s model an array is a store, the list of its element locations, and each element is a location holding a value. store bounds changes to stores: which indices hold an element. value bounds changes to every other location, the ordinary ones: object fields, variables, and the contents of array elements. Each dial orders its settings keep, then grow (store only), then any; one footprint is within another when each of its dials allows no more. Memory the call allocates itself is always free to change.
