Two rules that decide how far it reaches

A statement holds everywhere and depends on its callees

Over the whole domain

The statement must hold for every receiver and argument the signature admits. An arrow’s or function expression’s statement is proved once, at a signature admitting every argument its annotation admits, so it does not depend on what a call site passes; a generic one is refused (“Forms that cannot carry a statement”).

Contract closure

A call through a method, field or parameter counts at the statement its type carries, since such a value may hold any function; one stating nothing defeats the statement. A stated function’s callees must be one of:

  • a method, field or parameter stating an effect within it;
  • a non-generic function declaration of the same module that no code reassigns (TScert finds its effect from its code), or an imported function stating an effect within it;
  • a built-in whose contract states a footprint within it;
  • for a statement without onThrow, a function whose result type is never (no normal return to bound);
  • a function defined in the body, whose own calls meet the same rule.

A try/catch in a stated body may catch a call’s throw only if the callee states onThrow.

TScert’s parser makes many of its calls through Gate’s fields (next slides), so stating an effect on one of its functions means stating it on everything it reaches that way.
