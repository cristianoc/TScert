  • What it is: pattern parses a destructuring pattern, such as { a, b = f() }. For an object pattern it maps the elements other than a rest ...r (whose dotDotDotToken is set) to a PatternPropAst each, the parsed form of one property. filter’s callback calls nothing. The map’s callback (besides gate.fail, typed never, and ts.isIdentifier, not shown), whose default_ is the property’s default expression parsed, calls gate.pattern (pattern itself, on the element’s name; names collects the names bound so far) and gate.expr, the expression parser, on its default: both module functions in Gate’s fields, so the calls rely on the statements the fields’ types carry (“A field holding a module function”).
  • Reach: in the census run at commit 6a3a864, before the statements, 21 slices stop first at this map: pattern’s, forOfPattern’s (the parser of a pattern in for (const { a } of xs)), and 19 others whose slice includes pattern. With the statements, pattern’s and forOfPattern’s slices verify (census slices at 300 s, 2026-10-24), and the other 19 stop at other places (“What to expect”).
  • Cost: to keep the map’s result hole-free, pattern and expr state an effect, and so does what they reach through Gate’s fields and methods. pattern calls itself through the field gate.pattern, whose type carries pattern’s own statement: the call relies on it by the rule for calls through a field (“A field holding a module function”), which is not circular, since the function written into the field is checked against its type there.
