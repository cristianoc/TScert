TScert · method effects in practice

Using method effects: examples and outcomes

TScert checks type claims about TypeScript programs: it verifies a function when it proves the function safe, and otherwise refuses it (next slides). A function can state what it may change, and TScert checks the statement against the function’s body. Statements are certified (next slides) on test cases and on three functions of TScert’s own parser for TypeScript (“Statements around Gate”; Gate is the class holding the parser’s state). Of 16 parser functions measured, 9 verify, the same count with and without the statements (2026-10-24); 6 of the other 7 are refused first at one call of Array map in the parser (“pattern’s map needs the expression parser to state its effect”; what it takes and what to expect follow there). The 16 are described on “More terms, for TScert’s own source”.
