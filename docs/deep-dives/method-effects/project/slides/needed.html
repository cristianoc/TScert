What expr’s statement needs

D-numbers: decisions of the design document

Five requirements for expr’s statement

  • forEachChild. By the same scan, 20 of the 166 functions call TypeScript’s forEachChild, which calls a visitor function on each child of a syntax node. Its contract needs one signature per visitor footprint, as map’s has (“Built-ins state footprints in their contracts”) (design decision D7).
  • TypeScript’s type checker. The parser reads type annotations through a scope, an object of type TermScope whose function fields resolve names and types. Values of that type made by TScert’s reader of declaration files (the part of its front end that reads .d.ts files) query TypeScript’s own type checker, part of the TypeScript compiler and distinct from TScert’s checker, so a statement on TermScope’s members needs those queries bounded by a contract, reviewed by hand (design decision D8; the alternative is a scope type of the parser’s own).
  • The shift calls. shift on an array the call did not allocate allows any change to stores. Design decision D5 rewrites these shifts, an exception to the rule that TScert’s source is not rewritten to fit the verifier (design document §5; approved 2026-10-23, WORK.md): Gate’s four shifts on its two stacks of scopes (in its methods enterTypeParams and leaveTypeParams) become field writes, such as this.typeParamScopes = this.typeParamScopes.slice(1), within value: any, store: keep, and unobservable, since no other code holds either array (design document §5); the two shifts in closures of protocolForOf (the parser of for-of over an iterable), on lists allocated before each closure’s call, become reads at counters.
  • A checker rule for a method call on a value of several shapes, such as n.getText() on a Node, made in a TypeScript statement: TScert reads and calls it as one step, which the checker has no rule bounding, so the producer proposes no footprint for it and a body making it cannot have a statement certified (design document §10). Gate’s own methods make such calls (span calls node.getStart). The same call in an arrow’s expression body keeps the methods’ contract (test case compiler-api-node-method-effect.ts).
  • Statements on everything expr reaches: each certified where a verifying slice includes it, and callers otherwise verified relative to it.
