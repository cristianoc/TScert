Using it on TScert’s own code

More terms, for TScert’s own source

Slice and census

A slice is one top-level function of tools/ (TScert’s TypeScript front end) plus the definitions of its own file it uses, run alone through TScert; definitions of other files, such as Gate’s class, are read at their declared types. It stops at the first place TScert refuses. The census runs every slice: 488 slices, one per function of tools/, in the census run at commit 38ed032 (2026-10-24); the census at commit 6a3a864 (466 slices) predates the statements.

Gate

The class holding the state of TScert’s parser for TypeScript. Besides its data fields, its methods are of two kinds: its own, such as span, and fields holding module functions of other files, such as expr and pattern (later slides), called as gate.expr(…).

The 16 measured

16 functions of three parser files (fragment-statements.mts, fragment-expressions.mts, fragment-classes.mts): the 11 that the design document (docs/drafts/method-effects.md) names for measuring, and 5 others that WORK.md, the project’s status file, records. Each runs as a slice; the stages lowering (the parsed program to TScert’s calculus, the core language its checker reasons about), producer, search, checker and explanation (the stage that locates and explains a refusal) each may take 300 s before it counts as a timeout.

The 16: enumMembers, enumOpen, resolve, moduleFunction, inertRead, collect, inert, patternDefaults, steppedPattern, pattern, forOfPattern (these 11 verify); protocolPattern, patternStmt, neverAssigned (stopping later, “What to expect”), abrupt (refused inside the function markEarly, census of 38ed032); classBody.
