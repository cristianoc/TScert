Using it on TScert’s own code

More terms, for TScert’s own source

Slice and census

A slice is one top-level function of tools/ (TScert’s TypeScript front end) plus the definitions of its own file it uses, run alone through TScert; definitions of other files, such as Gate’s class, are read at their declared types. It stops at the first place TScert refuses. The census runs every slice: 466 slices, one per function of tools/, in the census run at commit 6a3a864 (2026-10-24), the baseline, which predates the statements.

Gate

The class holding the state of TScert’s parser for TypeScript. Besides its data fields, its methods are of two kinds: its own, such as span, and fields holding module functions of other files, such as expr and pattern (later slides), called as gate.expr(…).

The 16 measured

16 functions of three parser files (fragment-statements.mts, fragment-expressions.mts, fragment-classes.mts): the 11 that the design document (docs/drafts/method-effects.md) names for measuring, and 5 others whose measurements WORK.md, the project’s status file, records; 40ab4d7’s commit message names 15 of them. Each runs as a slice; the stages lowering (the parsed program to TScert’s calculus, the core language its checker reasons about), producer, search, checker and explanation (the stage that locates and explains a refusal) each may take 300 s before it counts as a timeout.

The 16: enumMembers, enumOpen, resolve, moduleFunction, inertRead, collect, inert, patternDefaults, steppedPattern (these 9 verify); pattern, forOfPattern, protocolPattern, patternStmt, abrupt, neverAssigned (stopping at pattern’s map); classBody.
