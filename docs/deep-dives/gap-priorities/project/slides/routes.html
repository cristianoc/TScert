How a refusal is answered · SOURCE-REWRITES.md

The first route that establishes the obligation at acceptable cost

RouteWhat the route requires
1. SupportA rule or external contract admits the construct
2. A runtime checkAn executable check establishes the whole property
3. A repairThe source corrects a defect the refusal reveals
4. AvoidanceAn equivalent source form avoids costly support
5. A host boundaryAn external service’s operation has no model. Only values made by that service meet the small module’s signatures. Callers use its audited contract and effects; the module stays refused
6. A trusted unitLocal code is exempt from checking, with the owner accepting its full contract as an assumption
7. A proofA Lean proof establishes the needed fact in the model
8. The refusal staysNo route establishes the obligation at acceptable cost
  • Before choosing a route, check whether TScert’s source discards information it already checked. A decoder’s closing assertion also needs scrutiny of storage contracts. This ranking identifies sites and evidence limits; a route requires its own justification.
