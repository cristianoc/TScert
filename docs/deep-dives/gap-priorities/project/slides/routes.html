How a refusal is answered · SOURCE-REWRITES.md

The first route that establishes the obligation at acceptable cost

RouteWhat the route requires
1. SupportA rule or external contract admits the construct
2. A runtime checkAn executable check establishes the whole property
3. A repairThe source corrects a defect the refusal reveals
4. AvoidanceAn equivalent source form avoids costly support
5. A host boundaryA small wrapper module performs an external service operation with no model. Its signatures admit only that service’s values. Its functions stay refused; callers assume its audited result and effect contract
6. A trusted unitLocal code is exempt from checking, with the owner accepting its full contract as an assumption
7. A proofA Lean proof establishes the needed fact in the model
  • Effect: a contract may bound how a call changes stored values. A host boundary’s result and effect are assumptions about its code.
  • Before choosing a route, check for discarded type information and for assertions over storage whose writes the checks do not constrain. Construct 13’s record-to-index refusal protects keys its named fields do not describe; construct 18’s lookup may find inherited methods.
