Use the first route that establishes the obligation at acceptable cost

RouteWhat the route requires
1. SupportA rule or external contract admits the construct
2. A runtime checkAn executable check establishes the whole property
3. A repairThe source corrects a defect the refusal reveals
4. AvoidanceAn equivalent source form avoids costly support
5. A host boundaryA small wrapper performs an external service operation with no model. Its functions stay refused; callers assume its audited result and effect contract
6. A trusted unitLocal code is exempt from checking, with the owner accepting its full contract as an assumption
7. A proofA Lean proof establishes the needed fact in the model
  • Before choosing a route, inspect whether the code discards information it already has. An external declaration is a specification to audit. A successful small case can establish a route for its construct while the larger census function reaches another refusal. Later obligations are outside this record’s first-refusal ranking.
