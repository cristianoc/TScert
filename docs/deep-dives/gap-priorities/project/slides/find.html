  • The census: each top-level function of tools/ is copied, with what it uses, into a file of its own (a slice) and run through TScert (make census). A refused function stops at its first reason. The verified census ran at 8092044, whose tools/ is b81675f's.
  • The diagnostic census: make census DIAGNOSTIC=1 runs each copy past every refusal: it replaces what it cannot check by an opaque region of assumed type and goes on, so it reports every refusal a function meets. It never reports a function verified.
  • Causes: every refusal naming one construct counts, at whatever stage. Each cause is weighted by the statements (an if, a return, an assignment …) of the functions it blocks, and by their number. A refused read whose own object an inner read already failed on (x.a.b after x.a) counts under the inner one.
