  • The census: each top-level function of tools/ is copied, with what it uses, into a file of its own (a copy, also called a slice) and run through TScert (make census). A refused function stops at its first reason. A copy may hold several functions.
  • The diagnostic census: make census DIAGNOSTIC=1 runs each copy past every refusal: it replaces what it cannot check by an opaque region of assumed type and goes on, so it reports every refusal a function meets. It never reports a function verified. It ran at acd7436, one commit after c62a911, which changes no file of tools/.
  • Causes: every refusal naming one construct counts, at whatever stage. Each cause is weighted by the statements (an if, a return, an assignment …) of the functions it blocks, and by their number. A function whose diagnostic run reports only reasons naming no construct (a failed search), or none before the limit, counts under its first refusal in the census at c62a911: the source at the place that refusal names is read for the construct there (a judgement).
