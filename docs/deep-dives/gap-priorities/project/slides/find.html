Part 1 · where proofs fail

The census, run past the first refusal

  • The census: each top-level function of tools/ is copied into a file of its own and run through TScert. At commit 963ffa4 (2026-10-24), 178 of 490 functions are verified and 312 refused (measured).
  • Past the first refusal: a refused function stops at its first reason. A diagnostic tool rewrites the copy crudely at each refusal and runs it again, so that later reasons show up too; its run finished for 210 of the 312 functions (measured). Every reason it meets, first or later, is kept.
  • Aspects: the gate's reasons are grouped by cause, an aspect. Each aspect is weighted by the statements (an if, a return, an assignment …) of the functions it blocks, and by the number of those functions. The later stages' reasons are left out: they vary from function to function.
  • One caveat: the function collectDeclarations has 2,334 statements and meets five of the heaviest aspects, so it dominates their statement weight; the function counts have no such bias.
