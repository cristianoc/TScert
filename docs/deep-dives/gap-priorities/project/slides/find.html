  • The census: each top-level function of tools/ is copied into a file of its own and run through TScert (make census). A refused function stops at its first reason.
  • The diagnostic census: make census DIAGNOSTIC=1 runs each copy past every refusal: it replaces what it cannot check by an opaque region of assumed type and goes on, so it reports every refusal a function meets. It never reports a function verified.
  • Causes: the refusals of reading the source (the gate, and the planning that lowers it) are grouped by cause and weighted by the statements (an if, a return, an assignment …) of the functions each blocks, and by their number. Refusals of the later stages differ from function to function and are left out. The function lowerFile, 674 statements, meets all seven heaviest causes.
