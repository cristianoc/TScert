  • The census: each top-level function of tools/ is copied, with what it uses, into a file of its own (a copy, also called a slice) and run through TScert (make census). A refused function stops at its first reason. A copy may hold several functions.
  • The diagnostic census: make census DIAGNOSTIC=1 runs each copy past every refusal: it replaces what it cannot check by an opaque region of assumed type and goes on, so it reports every refusal a function meets. It never reports a function verified. This time most of what it reports past a function's first refusal is a failed proof search tried at one point of the code alone, a reason naming no construct.
  • Causes: every refusal naming one construct counts. Each refused function also counts under its first refusal in the census of 945fa80: the source at the place that refusal names is read, in the copy of d373275, and the construct written there is the cause (a judgement). Each cause is weighted by the statements (an if, a return, an assignment …) of the functions it blocks, and by their number.
