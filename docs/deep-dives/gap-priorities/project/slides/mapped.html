  • Why it was refused: a mapped type {[P in K]: V} gives every key P the same field type V, and TScert read it only when V does not mention P. Partial, Readonly, Required and Pick write T[P], the type of T's own field P, so the gate refused them wherever they were written. In tools/, Readonly met 45 of the 51 functions, Partial 4 and Pick 3 (measured).
  • How it was closed, and why so: route 1, support: rules mapped-identity and mapped-pick. Over keyof T the type is T's own fields and indexes; over Pick's K, bounded by keyof T, the fields K names. Each marker ? and readonly is added, removed (-) or kept from T, as written. Readonly<Record<string, V>> is the readonly string index.
