Node's Buffer and its byte types

import { statSync } from "node:fs";

export function use(path: string): number { return statSync(path).size; }

  • Why it is not proven: the node:fs functions with no contract (statSync among them) are read through their declarations, which reach Buffer: Buffer.from returns Buffer<ImplicitArrayBuffer<TArrayBuffer>>, a conditional type over a type parameter, computed only once TArrayBuffer is known, and ArrayBufferLike is an indexed access into a named type. The gate refuses both (measured: 72 functions meet one of them).
  • What proving it needs: contract entries for the node:fs functions tools/ calls, at the arguments it uses, so their declarations are not read; and a contract for the Buffer values tools/ handles, read as the bytes they hold (Uint8Array), with the members it uses.
  • What it would trust: trust change: an audited entry for each function and for Buffer.
