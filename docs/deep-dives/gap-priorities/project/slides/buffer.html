gap blocker-node-buffer-contract

Node's Buffer, reached from node:fs

import { statSync } from "node:fs";

export function use(path: string): number { return statSync(path).size; }

  • Why it is not proven: statSync has no contract (the contracts for node:fs list readFileSync, writeFileSync, existsSync and a few others), so the gate reads its declaration and the types it names. They reach Buffer, whose method Buffer.from returns Buffer<ImplicitArrayBuffer<TArrayBuffer>>: a conditional type over the type parameter TArrayBuffer, which TypeScript computes only once TArrayBuffer is known, so the gate refuses it (tools/computed-types.mts:229). 19 of the functions also read the global Buffer, whose declaring file no contract lists (measured).
  • What proving it needs: contract entries for the node:fs functions tools/ calls, statSync among them, at the arguments it uses, so their declarations are not read; and a contract for the Buffer values tools/ handles, read as the bytes they hold (Uint8Array), with the members it uses.
  • What it would trust: trust change: an audited entry for each function and for Buffer.
