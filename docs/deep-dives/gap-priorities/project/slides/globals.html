A standard-library or Node global with no contract

// library-global-unreviewed: Math.random has no contract

// blocker-weakmap
export function use(): void { const values = new WeakMap<object, number>(); }

  • Why it is not proven: a global of JavaScript's standard library is read only through a contract that lists its exact declaration (SOURCE-CONTRACTS.md, “Library globals”). Missing in tools/ (functions met, measured): Object.hasOwn (14), process.execArgv (12), Object.getPrototypeOf (8), process.platform (7); and WeakMap, WeakSet and Uint8Array, declared in TypeScript's library files (lib.es2015.collection.d.ts, lib.es5.d.ts), which no contract lists as a source of globals.
  • What proving it needs: for a function or a property, a contract entry after an audit of what the host does: for Object.hasOwn, that a null or undefined object throws and a key of type string, number or symbol runs no code while it is converted. For WeakMap and WeakSet, a contract for a class read through its members (construct, get, set, has, delete), which TScert has no form for today; Uint8Array goes with Buffer (aspect 7).
  • What it would trust: trust change: each entry is an assumption about the host, stated and audited.
