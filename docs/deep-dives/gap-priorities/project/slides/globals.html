A standard-library or Node global with no contract

// library-math-random: verified
export function rolls(sides: number[]): number[] { return sides.map((n) => Math.ceil(Math.random() * n)); }
// blocker-weakmap: a gap
export function use(): void { const values = new WeakMap<object, number>(); }

  • Why it is not proven: a global of JavaScript's standard library is read only through a contract that lists its exact declaration (SOURCE-CONTRACTS.md, “Library globals”). Math.random, Object.hasOwn (14 functions met, measured), process.execArgv (12), process.platform and process.arch have audited contracts, and their cases verify (also object-has-own and node-process-platform); the weight above counts them. Still without one: WeakMap, WeakSet and Uint8Array, for which no contract lists an entry; and Object.getPrototypeOf (8 functions), refused on purpose. TScert reads Array.isArray(x) and x instanceof Array as one test, true of every array, since every array a program reaches inherits from Array.prototype. Object.getPrototypeOf([]) returns Array.prototype itself, an array the two tests disagree on, through which a program could write into every array (case invalid-get-prototype-array-prototype, run under Node).
  • What proving it needs: for WeakMap and WeakSet, a contract for a class read through its members (construct, get, set, has, delete), which TScert has no form for today; Uint8Array goes with Buffer (aspect 7). For Object.getPrototypeOf, a result type no array test narrows to an array, which TScert has no form for either.
  • What it would trust: trust change: each entry is an assumption about the host, stated and audited.
