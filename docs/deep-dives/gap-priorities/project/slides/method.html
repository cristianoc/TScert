Rank the first observed construct, not a generic error message

  • One function, one first refusal: read its saved slice at the recorded source span. All saved slice hashes match the census. Shared recursive text still represents each named function separately. Later refusals are outside this ranking.
  • One construct per group: split generic search failures using their source expressions and input contracts. The tables name observed constructs, not proved causal defects. A missing source location stays an unlocated obligation; it is not assigned an invented cause.
  • The priority weight: a function with n statements contributes 10 / (10 + n). A 10-statement function contributes 0.5; a 90-statement one, 0.1. Add contributions for a group and sort by the full value. Tables round to three decimals. Smaller functions often have fewer later refusals.
  • An existing host boundary: a small wrapper performs an external operation outside the model. Callers use its audited contract; its implementation remains refused. Rows 7, 14 and 19 are documented examples, whose implementation refusals alone call for no new language support.
  • Choosing work: weights rank observed refusals. Choose further cases after checking which routes already answer or restrict them. Counts describe blocked code, not promised gains; all 190 functions and their 10,228 statements contribute once.
