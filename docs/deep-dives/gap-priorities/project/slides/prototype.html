Object.getPrototypeOf, confined to a host boundary

The use

The compiler channel (compiler-channel.mts), the front end's link to TypeScript's compiler process, checks and wraps the six request methods of its private client, on the client's class prototype: 8 functions reached it (measured).

Why no other route

An entry (o) => object | null is unsound: Array.isArray narrows getPrototypeOf([]) to an array whose writes reach every array; instanceof narrows a prototype to an instance without its fields. No rewrite avoids it: a read through the client can run a getter.

What it prevents

A caller's callback cannot supply an answer: the boundary returns each itself, rethrows a failed request, and refuses a send kept for later.
