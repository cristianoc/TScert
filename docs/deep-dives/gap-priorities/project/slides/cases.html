  • A case example: is the smallest source with the cause's refusal; one made from a census names in its header the census functions it stands for. The test suite (make suite) checks its expected outcome on every run.
  • A gap case: is a safe program TScert refuses for want of a rule or a contract. A negative case is a refusal that is right: the program could produce a wrong value.
  • This census: seven of the ten heaviest causes, numbered on the next slide, have no case. The source above, not yet a case of the suite, reproduces cause 5 (measured). For causes 1 and 2 no small source is found yet: the same shape over the program's own types verifies (cause 1, measured), and a source over compiler nodes needs the compiler interface's contract, which a scratch project does not load. Writing these cases is the next step.
