TScert · which gaps to close first

Nine gap cases behind the heaviest blockers of TScert's own code

TScert is run on its own front end (the code that reads TypeScript sources, in the folder tools/), function by function, and most functions are refused. This deck ranks the reasons for those refusals, including the ones met after the first, by how much of the code each one blocks; picks the largest, by statements or by functions, that existing gap cases show in a few lines: seven aspects, nine cases; and says for each why TScert does not prove it today and what proving it needs.
