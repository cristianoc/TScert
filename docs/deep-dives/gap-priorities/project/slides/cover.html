TScert · its own front end

Where TScert's proofs of its own code fail, and which cases to close first

TScert is run on its own front end (the code that reads TypeScript sources, in the folder tools/), function by function, and many functions are refused. Part 1 finds where the proofs fail, with a census that goes past each function's first refusal, and turns each cause into a small case example. Part 2 shows how five of the six causes the last version of this deck left open were closed, what two changes of this round cost, and ranks the open causes by how much code they block.
