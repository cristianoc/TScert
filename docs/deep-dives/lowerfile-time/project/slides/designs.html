Proposed, not built

Three designs for the producer, by expected gain

  • Entry environments in one evaluation: evaluate a statement once while typing it, in evaluation order, handing each sub-expression the environment the evaluation has reached. A rerun sees the claims typed so far, so the design must show it gives the environments the reruns give, or record the claims each step reads and rerun only when one changed. Expected: one evaluation per statement instead of 27 in the slice; estimated −18 s in the slice and −11 s in the four modules measured.
  • Passes only where an assumption changed: type the functions callee before caller, in the order of the call graph, so a function is typed once its callees' effects are final; a recursive group is iterated alone. Expected: lowerFile typed in one effect round, 4 → 2 passes, an estimated −3.5 s once the first design lands; the closure pass stays.
  • Shared, numbered types: build each distinct type once and give it a number, so two types are equal exactly when their numbers are; union, join and lookup then compare numbers. Expected gain not measured; the largest change of the three, touching every module of the producer.
  • With the first two and one import round, the producer's 64 s of CPU in this check would fall to an estimated 25 s, before the third; with the plans saved too, the check would take about 60 s, the compiler's 20 s and the search among them.
