TScert · run time of one census slice

Where lowerFile's 239 seconds go

TScert checks type claims about TypeScript programs and is run on its own front end, one function at a time. Checking the function lowerFile of tools/fragment-parse.mts took 239 s, with no earlier result to reuse. This deck attributes that time to the steps of the check and, inside the slowest one, to what it repeats. Two repairs of data structures, which change no output, bring the check to 108 s. Of those, about 30 s follow the size of the program; of the producer's remaining 64 s, 30 s are measured repetition, and three designs are proposed for it. The next slide explains the words.
