1 · A table for the join

Each environment of a join is indexed once by name (a hash table keeping the first binding of each name, which is what the list lookup finds), and every binding is looked up there. The joined environment is the same list, in the same order.

2 · Uniting sorted lists by merging

A type is often a list of alternatives kept sorted without repeats. Uniting two such lists sorted their concatenation again; it now merges them in one pass when both are sorted, and sorts otherwise. The result is the same list.
