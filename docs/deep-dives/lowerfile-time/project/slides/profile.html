Measured: sampling profiler, and a build counting each lookup

93% of the slice's proposal is looking up names in lists

  • Sampled: 1 ms samples of the running proposal: 93% inside OCaml's List.assoc_opt, the standard lookup in a list of pairs, almost all of it comparing names.
  • Counted: the join's lookups (the two shown, and two more in the join and the function calling it) ran 34.2 million times each and visited 3.7 to 3.8 billion list cells each: about 110 cells per lookup.
  • Why: an environment is a list, so a lookup walks it, and a join makes ≈100 such walks where a table answers each lookup directly.
