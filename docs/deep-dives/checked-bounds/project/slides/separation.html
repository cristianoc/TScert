A guarded separation keeps a length across a regional call

type Runs = { /** @stable */ readonly open: number[] };
function step(runs: Runs | null, out: number[]):
    Modifies<{ values: "any"; stores: "grow";
      "runs.open[*]": "any" }, void> {
  if (runs !== null) runs.open.pop(); out.push(1);
}
/** @requires safeInteger(to) && 0 <= to && to <= xs.length */
export function f(xs: number[], out: number[],
    to: number, use: boolean): number {
  const runs: Runs = { open: [] };
  const chosen = use ? runs : null;
  let s = 0;
  /** @invariant safeInteger(i) && safeInteger(to) && 0 <= i
   *    && to <= xs.length
   *  @invariant chosen === null || xs !== chosen.open */
  for (let i = 0; i < to; i++) {
    step(chosen, out); s += xs[i]!; }
  return s;
}

  • Regional growth: step may change the array runs.open holds, its region, and may grow every other array: a lower bound of the length of an array apart from the region survives the call.
  • Guarded separation: chosen === null || xs !== chosen.open: where chosen is null the region selects no array, elsewhere xs is another array, so to <= xs.length survives step(chosen, out). The producer proposes separations through copies, conditional declarations and joins of control flow; the checker checks each on every edge.
  • Writes: a separation read through a @stable field also survives element and field writes: the field holds its array for the record’s life.
  • In pretext: a measuring loop passes its record or null to a helper stating such a region; its loop invariant states this guarded separation.
