  • Frame: a function states what it may change in its result type, Modifies<P, T>, which TypeScript reads as T. P maps each kind of location to how it may change: values (fields and variables), stores (arrays’ elements and lengths), or one array named by a path such as "runs.openBrackets[*]". A location P leaves out is unchanged. The body is checked against P.
  • Separation: a !== b of two plain arrays in a clause states that their storage differs. A caller proves it, for instance from a fresh literal []; @stable keeps the path naming the same array across calls.
  • Rule: a length fact survives a call whose frame changes only arrays separate from it.
  • Scope: paths through one @stable field. Typed arrays may share a buffer, so !== of them is refused.
