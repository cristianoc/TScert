Argument paths · frame and separation

the frame and the kept facts proved

A frame names one array; a caller keeps what is apart from it

type Runs = { /** @stable */
  readonly openBrackets: number[] };
function readRuns(runs: Runs): Modifies<
    { values: "any";
      "runs.openBrackets[*]": "any" }, void> {
  runs.openBrackets.splice(0, 1); }
/** @requires flags !== runs.openBrackets */
function measure(flags: number[], runs: Runs) {
  for (let i = 0; i < flags.length; i++) {
    readRuns(runs); sum += flags[i]!; } }

  • The frame: readRuns changes the array at runs.openBrackets and value locations; every other store is unchanged. Its body is checked against that.
  • Separation: flags !== runs.openBrackets of two plain arrays states that their stores differ. A caller establishes it, here from a fresh []; an aliased call cannot.
  • Kept facts: across the call, i < flags.length holds, since the changed store is apart from flags’s; the @stable field keeps the separation through the loop.
  • Scope: paths of one @stable field; a frame with paths called inside another such function is not composed; !== of typed arrays, which may share a buffer, is refused.
