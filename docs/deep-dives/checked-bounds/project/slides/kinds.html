Contract support

C is a clause of the shared language

Preconditions, postconditions and invariants

ContractSupport
Preconditionwritten as @requires C; checked at analyzed calls, assumed by the body
Postconditionpartial: result facts from native specifications and type invariants; no written postcondition syntax
Type invariantwritten as @invariant C on a type; obligations at function boundaries
Loop invariantwritten as @invariant C before a loop, or inferred; checked on every edge into the head

Clauses are linear relations over values, field paths and lengths, under null guards, and quantified clauses forall i in xs: B over an array’s elements. A heap change preserves no quantified fact: a stated limit.
