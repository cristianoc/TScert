C is a clause of the shared language

Preconditions, postconditions and invariants

ContractSupport
Preconditionwritten as @requires C; checked at analyzed calls, assumed by the body
Postconditionpartial: result facts from native specifications and type invariants; no written postcondition syntax
Type invariantwritten as @invariant C; obligations at function boundaries
Loop invariantinferred: checked on incoming edges; no written loop-invariant syntax

The clause language expresses scalar linear relations. Quantified bounds over array elements and written loop invariants are proposed extensions.
