  • Measured: length invariants on PreparedLineBreakData: 137 functions verified against 144 without them; 9 lost, 2 gained.
  • Return obligation: a parameter never reassigned must satisfy its invariant at every normal return.
  • Frame condition: the calls may change field references, so the checker drops the equality even where array lengths are preserved.
  • Recorded calls: Map.set on module caches, getEngineProfile, onLine callbacks, measurement helpers.
  • Default argument: start = TEXT_START_CURSOR receives no invariant precondition.
  • Proposed: more precise modifies clauses; proof obligations for supplied and default argument values.
