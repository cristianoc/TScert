Frame conditions

the preservation rules proved

Mutations preserve facts through checked effects

A fact over the heap reads particular locations. TScert’s footprint mechanism, its frame conditions, checks whether an operation leaves those locations unchanged, or changes them in a way that preserves the inequality.

These rules concern normal returns; a throw carries a frame condition only where one is stated for it.
