Re-establish the invariant at function boundaries

/** @invariant this.segmentFlags.length
 *     === this.widths.length
 *  @representation PreparedLineBreakData */
export type PreparedText = {
  readonly [preparedTextBrand]: true
}

  • Meaning: the symbol property brands an opaque handle; @representation names the record behind it.
  • Entry and return: callers establish parameter invariants; bodies establish result invariants, and restore those of parameters never reassigned.
  • Casts: a cast into the handle checks the representation type; the invariant is checked at the boundary that requires it.
  • Between boundaries: each fact needs a preservation argument (next slide).
