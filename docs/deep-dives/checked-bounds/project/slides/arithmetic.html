the rules proved against Lean’s model of IEEE doubles

Integer reasoning over exact JavaScript arithmetic

Σᵢ cᵢ·tᵢ ≤ d

Σᵢ cᵢ·tᵢ ≠ d

(cᵢ, d integers)

  • Safe integers: a numeric term denotes an integer only within ±(2⁵³ − 1). Fractions, infinities and NaN denote nothing, so no fact about them holds.
  • Exact addition: r = a + b holds when the operands are safe integers and the known facts bound the sum within that range; there the double sum is exact.
  • Terms: values, field paths p.f.g, array lengths (at most 2³² − 1) and typed-array lengths. A term is partial: where its path meets no object, it denotes nothing.
  • Branch facts: on safe integers < and === are integer order and equality: the true branch of i < n gives i ≤ n − 1, the false branch n ≤ i.
