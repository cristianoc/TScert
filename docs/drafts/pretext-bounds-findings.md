# Eliminating Pretext's remaining bounds checks

This audit uses the [Pretext bounds catalogue](tolerant-frames-patterns-note/note.tex), the annotated Pretext source, and the prover and cases at TScert revision `0f5dd12da`. It also reads `a5238a9d0`, the in-progress #356 work, for the guarded parallel-array rules and walker annotations. The pattern numbers refer to the catalogue's historical corpus. The changes below are proposals from source inspection. The [work list](../../WORK.md#status) owns verification progress.

## Prepared data, walkers, and materialization

**Parallel arrays and indexed elements (P12, P17).** A paragraph may append `null` to `breakableFitAdvances` and later replace an entry with a nonempty advance list. The #356 branch states that the array has one entry per width and that non-null entries are nonempty. To establish those facts, extend the proved transfer for an append or exact dense write. Frame the old entries and instantiate the guarded clause at each new or replaced entry. A null entry satisfies the null alternative. A non-null entry needs its length fact, including any relation to the parallel extras entry. `PromiseCalls.every_appended` supplies the append proof for the simpler single-integer case. Reuse the indexed-element rule for the read, and carry the equal outer lengths and the loop index bounds through the walker heads. Establish guarded lengths for `insideExtras` and `fillExtras` at their builders and branch on each selected array's null test. Cross-field implications such as `a !== null || (b === null && c === null)` also need checked null and undefined tests as clause atoms. [Append and call rules](../../lean/Verification/Programs/PromiseCalls.lean) · [Line walker](../../dev/paper-rules/pretext/src/line-break.ts)

**Measurement and item counts (P2, P8).** In `measureAnalysis`, `at = base + mi - from` is the next output index. Use the existing write-at-length and two-state call rules to prove that the paragraph's parallel lists grow by `to - from` and that the next index stays within flags capacity. At the caller, instantiate the guarded postcondition on the actual paragraph lists and retain their read links through the final `subarray`. For `starts[to]`, transfer the equality of analysis lengths. For `starts[from]`, establish at each caller that nonzero `from` is below the starts length. For the neighboring flag reads, preserve `spaceBefore ⇒ mi > from` and the distinct bound for `mi - 2`. A separate two-state case needs the entry length term exposed by the checked parameter contract before a reflexive `old` fact can be used. [Measurement](../../dev/paper-rules/pretext/src/prepare.ts) · [Two-state postconditions](../ARITHMETIC.md#two-state-postconditions)

**Rich-inline materialization.** A read of `itemSegments[itemIndex + 1]` needs the final sentinel and a proof that a value from `segmentItems` names an item. Give the paragraph builder a quantified interval contract relating each segment to its item's start and end. Establish that the gap and source-offset lists cover those segments. Pass checked endpoint contracts to `createLine` and `getPartWidth`, including the branch where the end cursor lies within a segment. For `getPartWidth`, the indexed-element rule supplies the length after the caller establishes presence and non-nullness of the advance list. Externally supplied ranges still need a checked entry contract or validation. [Rich-inline builder and consumers](../../dev/paper-rules/pretext/src/rich-inline.ts)

**Rounded retreat and safe integers.** The retreat branch needs an integral `moved` with `1 <= moved <= count` to derive `0 <= count - moved < count`. Add range consequences for `Math.ceil` and `Math.min` under checked premises about the actual binary64 inputs and quotient. A positive mathematical quotient can round to zero. Establish the relevant domain or define source behavior for that case and for non-finite inputs. For the `SafeInt` loop-start gap, materialize the proved type facts on the call-result edge before the join and carry them onto the joined slot. `IndexWrites.typeInt` already handles unions of safe integer literals. Derive path integrality from a checked field read. [Arithmetic rules](../../lean/Verification/Semantics/ArithmeticRules.lean) · [Integer facts](../../lean/Verification/Programs/IndexWrites.lean)

## Framing, captures, and cache entries

- **Quantified facts across field writes (P3).** A fresh record field write should preserve the quantified fact over an unrelated typed array. The Lean support already distinguishes field cells from element cells. Locate the first missing fact in the existing refusal by checking `frameKept`, the loop-head meet, and `instantiateEvery` in order. The last step needs the element link and the bound at the read. The static audit leaves the first loss unresolved. [Field-write rules](../../lean/Verification/Programs/HeapExpressionRules.lean) · [Quantifier instantiation](../../lean/Verification/Semantics/HeapKnowledge.lean)
- **Fresh separation and field effects (P4, P6, P18).** The #356 branch records positive fresh-path and regional P4 cases. For the remaining straight-line comparison, prove exactness of `i + 1` from the successful bounded comparison under the checked integer and length premises, accounting for JavaScript rounding. For P6, certify the helper's field-only effect so its call keeps element facts on other regions. For P18, extend the stable-field read context to checked stable prefixes using `IndexedStates.Admissible.stablePath`, with separate support for absent fields and leaf spines. [Region support](../../lean/Verification/Semantics/Survival.lean) · [Stable paths](../../lean/Verification/Semantics/IndexedStates.lean)
- **Captured storage and defaults (P7).** Pass the captured Han-kerning arrays as arguments and use ordinary checked preconditions. To retain the closure form, bind capture locations in the closure contract and check the requirements at invocation. For a defaulted cursor, check the effective parameter after the default evaluates, or put a required-cursor helper behind the public default. [Closure entry facts](../../lean/Verification/Programs/GraphCode.lean) · [Default lowering](../../lean/Verification/Source/Lowering/Closures.lean)
- **Module constants, lazy cells, and collections (P15, P16, P20).** A fixed tuple can state a fixed table length. A lazy-cell invariant such as `cache === null || cache.length === N` needs a proof at initialization and every writer, outside noninterference, and a checked way to import the fact at unit entry. For collection reads, check the value invariant at insertion and every permitted mutation through an entry alias, then recover it on a hit. The same mechanism should cover the dictionary used by `getBreakRules` and the paper's reduced `Map` example. [Module initialization](../../lean/Verification/Source/Claims/PassUnitInit.lean) · [Break-rule cache](../../dev/paper-rules/pretext/src/line-breaks.ts)
- **Visitor effects in the ordinary CLI (P1, P22).** The paper prototype checks callbacks against bounded effects. An ordinary certified verdict requires effect-variable arrow contracts, checked instance substitution and rebasing, an entry-relative separation proof for storage allocated in the body, and a call transfer proved over the ordinary indexed heap. That proof replaces `paperKeptFactsSurvive`. The callback's effect remains a contract for external callers. [Prototype proof boundary](paper-rules-mode.md#the-prototype)

## Strings, table indices, and prefixes

- **String indexing (P11).** Lowering already emits an element read. Add a knowledge-sensitive certificate choice using `ArithmeticRules.strRead_sound` to certify a string of UTF-16 length one when the index is proved in range. Carry the existing nonempty-needle search bound around the whitespace-removal loop. [String read rule](../../lean/Verification/Semantics/ArithmeticRules.lean) · [Certificate producer](../../lean/Verification/Programs/CertificateProducer.lean)
- **Normalization and native strings (P14).** Audit a non-expansion postcondition for native regex replacement using the minimum consumed UTF-16 length and the expanded replacement length. Include the match-width fact in the certified native contract. Reuse bounded slice contracts and add clamped forms where needed. To bound writes to `mapSourceLineBreaks`' smaller destination, prove its scanner counts exactly the units emitted by normalization, using a shared verified count or emitter. State nonempty regex split output under a checked positive match width and a limit that permits output. [Normalization](../../dev/paper-rules/pretext/src/analysis.ts) · [Native contracts](../SOURCE-CONTRACTS.md)
- **Decoded contents and variable strides (P5, P9, P21).** Certify the bundled packed literals and their decoder relation. For `getClass`, prove the code point domain, index length, values length of `256 * blocks`, and a block ID below `blocks` at every index. The existing shifts, mask, and OR then give the final index bound. Certify map-specific class ranges and state and lookahead targets for their consumers. For `state * width + column`, add a checked stride rule using exact safe-integer product and addition and the state and column limits. Preserve table-content predicates across cache access and writes through overlapping views. [Table readers](../../dev/paper-rules/pretext/src/line-breaks.ts) · [Arithmetic rules](../../lean/Verification/Semantics/ArithmeticRules.lean)
- **Shared counts and running sums (P10, P19).** Give spacing and advance builders a common grapheme count or boundary sequence, keyed by the text and grapheme-table identity. State the empty spacing sentinel and nullable advance cases explicitly. For `findSegmentSources`, prove that `alignToSource` returns one offset per normalized unit, prove segment nonemptiness where the code reads the last unit, and relate both `segments.join('')` and the loop's `at` to the same prefix sum. [Measurement](../../dev/paper-rules/pretext/src/measurement.ts) · [Source offsets](../../dev/paper-rules/pretext/src/rich-inline.ts)
- **Prefixes and native arrays (P13).** Reuse `writtenPrefix` for the parameter-buffer case. Use a named successor in the reduced case to distinguish a loss at counter update from a loss at quantified return or postcondition composition. State guarded capacity, prefix range and ordering, and final endpoint where `findGraphemeEnds` supplies Gecko's scan. To transfer element facts through a subview, track the backing-byte offset and overlapping writes. For native arrays, expose `map`'s result length as `old(this.length)` independently of density, and track exact sparse allocation length and only the interval written by a partial fill. Every slot filled with an object receives the same reference. [Prefix transfer](../../lean/Verification/Programs/PromiseCalls.lean) · [Bounds cases](../../pipeline/cases.mts)

## Three uncatalogued sites

- `scanStarts[k]` needs a dense start list with the same length as `paragraph.atomic`, in both normalization paths.
- `sourceBreaks[after]` needs an atomic start strictly below the source length and the loop invariant `0 <= after <= source.length`. The Gecko result contract supplies the extra sentinel entry.
- `openBrackets[opened + 1]` needs a successful search to pick the even code slot of a dense pair. Encode the stack as code/script pairs, or prove the flat stack has even length, that the search key cannot match a script slot, and that each push and splice preserves pairing.

## First implementation step

Prove the guarded exact-write and append transfer for a dense array of nullable lists. Use the two writes in `measureAnalysis` as the first consumer, then prove the same paired-length postcondition at `prepareRichInline`'s call. This gives the walker an established outer bound and an element fact at one checked index while exercising the same proof across construction, a helper call, and a loop.
